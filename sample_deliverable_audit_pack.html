1. Contrôle des En-têtes HTTP Défensifs (OWASP) & Fuites Serveur

En-tête HTTP État Risque couvert Directive recommandée
strict-transport-security Manquant Protège contre le déclassement SSL et l'interception de trafic (MITM). max-age=31536000; includeSubDomains; preload
content-security-policy Manquant Bloque l'exécution de scripts non autorisés et les attaques XSS. default-src 'self'; script-src 'self'; object-src 'none';
x-frame-options Manquant Empêche l'inclusion du site dans des iframes malveillantes (Clickjacking). DENY
x-content-type-options Conforme Force le navigateur à respecter le type MIME déclaré (bloque les faux fichiers).
referrer-policy Manquant Limite la fuite d'URLs et de données sensibles lors de clics externes. strict-origin-when-cross-origin
permissions-policy Manquant Désactive les fonctionnalités matérielles invasives (caméra, micro, géolocalisation). camera=(), microphone=(), geolocation=()
  • Fuite d'empreinte serveur : server: nginx/1.18.0 (Ubuntu) — Supprimer ou masquer l'en-tête 'server' pour éviter la reconnaissance d'empreinte d'OS/serveur.
  • Fuite d'empreinte serveur : x-powered-by: PHP/8.1.2 — Supprimer ou masquer l'en-tête 'x-powered-by' pour éviter la reconnaissance d'empreinte d'OS/serveur.

2. Diagnostic d'Accessibilité Numérique (WCAG 2.1 AA / RGAA 4.1)

Vérification automatisée de la structure sémantique, des alternatives textuelles d'images, des étiquettes de formulaires et de la lisibilité visuelle.

Sévérité Règle WCAG / RGAA Diagnostic & Élément concerné
CRITICAL doc_lang La balise <html> ne spécifie aucun attribut 'lang'.
HIGH img_alt_tags 1 image(s) sans attribut 'alt' détectée(s).
MEDIUM links_accessible 1 lien(s) avec intitulé ambigu détecté(s) (ex: 'cliquez ici').

3. Correctifs Serveur Clé en Main (Prêts à Copier-Coller)

Origines externes détectées dans la page et autorisées dans la politique CSP : https://cdn.jsdelivr.net, https://fonts.googleapis.com

Option A — Configuration Nginx (/etc/nginx/sites-available/votresite.conf)

# === PACK CORRECTIF NGINX (PRÊT À COPIER DANS VOTRE BLOC server {}) ===
server_tokens off; # Masque la version exacte de Nginx
add_header Strict-Transport-Security "max-age=31536000; includeSubDomains; preload" always;
add_header X-Content-Type-Options "nosniff" always;
add_header X-Frame-Options "SAMEORIGIN" always;
add_header Referrer-Policy "strict-origin-when-cross-origin" always;
add_header Permissions-Policy "camera=(), microphone=(), geolocation=()" always;
add_header Content-Security-Policy "default-src 'self'; script-src 'self' https://cdn.jsdelivr.net https://fonts.googleapis.com; style-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net https://fonts.googleapis.com; img-src 'self' data: https:; frame-ancestors 'self'; object-src 'none';" always;

Option B — Configuration Apache (.htaccess)

# === PACK CORRECTIF APACHE (.htaccess) ===
<IfModule mod_headers.c>
  Header always unset X-Powered-By
  Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains; preload"
  Header always set X-Content-Type-Options "nosniff"
  Header always set X-Frame-Options "SAMEORIGIN"
  Header always set Referrer-Policy "strict-origin-when-cross-origin"
  Header always set Permissions-Policy "camera=(), microphone=(), geolocation=()"
  Header always set Content-Security-Policy "default-src 'self'; script-src 'self' https://cdn.jsdelivr.net https://fonts.googleapis.com; style-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net https://fonts.googleapis.com; img-src 'self' data: https:; frame-ancestors 'self'; object-src 'none';"
</IfModule>
