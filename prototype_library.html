/* Arbre AST & Style Allman */
Status_t ast_insert(Node_t** root, int val)
{
    if (*root == NULL)
    {
        *root = malloc(sizeof(Node_t));
        if (!*root) return ERR_NOMEM;
        (*root)->val = val;
        (*root)->left = NULL;
        (*root)->right = NULL;
        return STATUS_OK;
    }
    return (val < (*root)->val)
        ? ast_insert(&(*root)->left, val)
        : ast_insert(&(*root)->right, val);
}

Marginalia : L'Esprit d'Archiviste

L'amour des livres sur smartphone, la rigueur de la bibliothèque universitaire et l'anticipation stratégique du joueur d'échecs.

La lecture de traités sur un écran de téléphone exige une discipline typographique implacable : chaque mot doit justifier sa présence sur la page. C'est exactement cette économie de moyens que j'applique au code. Quand je conçois un logiciel en ISO C99 ou une API asynchrone, je refuse le gaspillage de cycles processeur et les abstractions superflues.


Mon apprentissage a été forgé dans le silence des bibliothèques et la clarté du terminal : après une scolarité scientifique au Lycée Polyvalent Cantau d'Anglet (Spécialités Mathématiques & NSI), j'ai rejoint le BUT Informatique de l'IUT de Bayonne et du Pays Basque (Campus d'Anglet) pour approfondir la machine au plus près du silicium.
