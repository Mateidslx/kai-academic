 NIVEAU 1 — CEINTURE BLANCHE (Exercice 1 — Plafond Note : Max 07/20)
================================================================================
MODÈLE OFFICIEL : Modèle 2 — La saisie-vérification d'une valeur

TEXTE DE JUSTIFICATION DU CARTOUCHE :
"Le nombre d'itérations est inconnu a priori car il dépend des erreurs de 
l'utilisateur. Au moins une saisie est obligatoire avant de pouvoir vérifier
la validité des bornes : structure for(;;) avec condition de sortie interne 
(break) et message d'erreur avant rebouclage."

CODE C++ CONFORME :
--------------------------------------------------------------------------------
/*
  Numéro du groupe : 16 (TP4)
  Nom du groupe : Les Flèches de la Précision
  Étudiants : Matéi De Saint Leger, Nicolas Gence, Jules Tison
  Numéro de Kata : Kata 1
  Numéro de l'exercice : 1
  But de l'exercice : Saisir et vérifier une valeur entière dans un intervalle borné.
  Modèle(s) d'algorithme(s) choisi(s) : Modèle 2 (La saisie-vérification d'une valeur)
  Brève justification du ou des modèles choisis : Nombre de tentatives inconnu d'avance,
  au moins une saisie requise avec message d'erreur si la valeur est hors bornes.
  Remarques éventuelles : Aucune valeur magique en dur.
*/
#include <iostream>
using namespace std;

int main(void)
{
    // CONSTANTES
    const short int VALEUR_MIN = -30; // Borne minimale autorisée
    const short int VALEUR_MAX = 50;  // Borne maximale autorisée

    // VARIABLES
    short int valeurSaisie; // Valeur entrée par l'utilisateur au clavier

    // TRAITEMENTS
    // (clavier) >> Saisir-vérifier la valeur >> valeurSaisie
    for ( ; ; )
    {
        cout << "Entrez une valeur comprise entre " << VALEUR_MIN << " et " << VALEUR_MAX << " : ";
        cin >> valeurSaisie;

        if ((valeurSaisie >= VALEUR_MIN) && (valeurSaisie <= VALEUR_MAX))
        {
            break; // Valeur correcte : arrêt de la boucle de saisie
        }

        cout << "Erreur : la valeur doit etre comprise entre " 
             << VALEUR_MIN << " et " << VALEUR_MAX << " ! Recommencez." << endl;
    }

    // valeurSaisie >> Afficher la valeur validée >> (écran)
    cout << "Valeur valide enregistree : " << valeurSaisie << endl;

    return 0;
}

 NIVEAU 2 — CEINTURE JAUNE (Exercice 2 — Plafond Note : Max 08/20)
================================================================================
MODÈLE OFFICIEL : Modèle 2 (Saisie-vérification) + Modèle 1 (L'échange de deux valeurs)

TEXTE DE JUSTIFICATION DU CARTOUCHE :
"Modèle 2 utilisé deux fois pour valider que les deux indices saisis sont bien
dans les bornes du tableau [0..TAILLE-1] et distincts. Modèle 1 utilisé ensuite
pour échanger les deux cases sans perte d'information à l'aide d'une variable
tampon temporaire du même type que les éléments."

CODE C++ CONFORME :
--------------------------------------------------------------------------------
/*
  Numéro du groupe : 16 (TP4)
  Nom du groupe : Les Flèches de la Précision
  Étudiants : Matéi De Saint Leger, Nicolas Gence, Jules Tison
  Numéro de Kata : Kata 1
  Numéro de l'exercice : 2
  But de l'exercice : Saisir deux indices valides et permuter les éléments correspondants.
  Modèle(s) d'algorithme(s) choisi(s) : Modèle 2 (Saisie-vérification) et Modèle 1 (Échange)
  Brève justification : Contrôle des indices dans l'intervalle valide puis permutation
  sécurisée à l'aide d'une case mémoire temporaire.
  Remarques éventuelles : Gestion du cas où les deux indices sont identiques.
*/
#include <iostream>
#include <string>
using namespace std;

int main(void)
{
    // CONSTANTES
    const unsigned short int TAILLE_TAB = 5; // Nombre d'éléments du tableau

    // VARIABLES
    int tab[TAILLE_TAB] = {10, 20, 30, 40, 50}; // Tableau d'entiers à manipuler
    unsigned short int ind1; // Premier indice saisi
    unsigned short int ind2; // Deuxième indice saisi
    int copieVal1;           // Variable temporaire pour l'échange (Modèle 1)
    unsigned short int i;    // Indice de parcours pour l'affichage

    // TRAITEMENTS
    // (clavier) >> Saisir-vérifier ind1 >> ind1
    for ( ; ; )
    {
        cout << "Entrez le premier indice (0 a " << (TAILLE_TAB - 1) << ") : ";
        cin >> ind1;
        if (ind1 < TAILLE_TAB)
        {
            break;
        }
        cout << "Indice invalide !" << endl;
    }

    // (clavier) >> Saisir-vérifier ind2 >> ind2
    for ( ; ; )
    {
        cout << "Entrez le deuxieme indice (0 a " << (TAILLE_TAB - 1) << ") : ";
        cin >> ind2;
        if (ind2 < TAILLE_TAB)
        {
            break;
        }
        cout << "Indice invalide !" << endl;
    }

    // tab[ind1], tab[ind2] >> Échanger les deux cases (Modèle 1) >> tab[ind1], tab[ind2]
    copieVal1 = tab[ind1];
    tab[ind1] = tab[ind2];
    tab[ind2] = copieVal1;

    // tab >> Afficher le tableau après échange >> (écran)
    cout << "Tableau apres permutation : ";
    for (i = 0; i < TAILLE_TAB; i++)
    {
        cout << tab[i] << " ";
    }
    cout << endl;

    return 0;
}

 NIVEAU 3 — CEINTURE JAUNE-ORANGE (Exercice 3 — Plafond Note : Max 09/20)
================================================================================
MODÈLE OFFICIEL : Modèle 3 — Parcours complet avec traitement systématique

TEXTE DE JUSTIFICATION DU CARTOUCHE :
"Le nombre d'éléments à traiter est connu à l'avance (taille physique ou logique
fixe). Chaque case du tableau doit être inspectée et traitée de manière 
inconditionnelle (affichage, cumul, inversion) sans aucun arrêt anticipé :
structure répétitive 'for' allant de 0 à EFFECTIF - 1 (ou à rebours)."

CODE C++ CONFORME (Calcul de moyenne & Affichage à rebours) :
--------------------------------------------------------------------------------
/*
  Numéro du groupe : 16 (TP4)
  Nom du groupe : Les Flèches de la Précision
  Étudiants : Matéi De Saint Leger, Nicolas Gence, Jules Tison
  Numéro de Kata : Kata 1
  Numéro de l'exercice : 3
  But de l'exercice : Calculer la moyenne des notes et afficher le tableau à rebours.
  Modèle(s) d'algorithme(s) choisi(s) : Modèle 3 (Parcours complet systématique)
  Brève justification : Nombre de cases connu, chaque élément doit être visité
  sans condition pour accumuler la somme puis afficher dans l'ordre inverse.
  Remarques éventuelles : Protection contre division par zéro.
*/
#include <iostream>
using namespace std;

int main(void)
{
    // CONSTANTES
    const unsigned short int EFFECTIF = 6; // Nombre de notes dans le relevé

    // VARIABLES
    float notes[EFFECTIF] = {12.5f, 8.0f, 15.0f, 10.0f, 14.5f, 9.0f}; // Tableau des notes
    float sommeNotes;            // Accumulateur pour la somme totale
    float moyenne;               // Moyenne calculée
    unsigned short int i;        // Indice de parcours de boucle

    // TRAITEMENTS
    // () >> Initialiser l'accumulateur >> sommeNotes
    sommeNotes = 0.0f;

    // notes, EFFECTIF >> Calculer la somme totale >> sommeNotes
    for (i = 0; i < EFFECTIF; i++)
    {
        sommeNotes += notes[i];
    }

    // sommeNotes, EFFECTIF >> Calculer la moyenne si possible >> moyenne
    if (EFFECTIF > 0)
    {
        moyenne = sommeNotes / EFFECTIF;
        cout << "Moyenne de la promotion : " << moyenne << " / 20" << endl;
    }
    else
    {
        cout << "Erreur : effectif nul, calcul impossible." << endl;
    }

    // notes, EFFECTIF >> Afficher le tableau à rebours >> (écran)
    cout << "Notes a rebours (de la fin au debut) : ";
    for (i = EFFECTIF; i > 0; i--)
    {
        cout << notes[i - 1] << " ";
    }
    cout << endl;

    return 0;
}

 NIVEAU 4 — CEINTURE ORANGE (Exercice 4 — Plafond Note : Max 11/20)
================================================================================
MODÈLE OFFICIEL : Modèle 4 — Parcours complet avec traitement conditionné

TEXTE DE JUSTIFICATION DU CARTOUCHE :
"Toutes les cases du tableau doivent être obligatoirement inspectées jusqu'au bout
(parcours complet par boucle 'for'), mais l'action (comptage, modification, affichage)
n'est déclenchée que si l'élément vérifie une condition booléenne ('if')."

CODE C++ CONFORME (Comptage et incrémentation des valeurs négatives) :
--------------------------------------------------------------------------------
/*
  Numéro du groupe : 16 (TP4)
  Nom du groupe : Les Flèches de la Précision
  Étudiants : Matéi De Saint Leger, Nicolas Gence, Jules Tison
  Numéro de Kata : Kata 1
  Numéro de l'exercice : 4
  But de l'exercice : Compter et incrémenter de 1 toutes les valeurs négatives d'un tableau.
  Modèle(s) d'algorithme(s) choisi(s) : Modèle 4 (Parcours complet avec traitement conditionné)
  Brève justification : Toutes les cases doivent être analysées, le compteur et
  l'incrémentation ne s'activent que lorsque tab[i] < 0.
  Remarques éventuelles : Prise en compte du cas où aucun nombre n'est négatif.
*/
#include <iostream>
using namespace std;

int main(void)
{
    // CONSTANTES
    const unsigned short int NB_VALEURS = 8; // Taille physique du tableau

    // VARIABLES
    int nombres[NB_VALEURS] = {-5, 12, -3, 0, 7, -1, -8, 14}; // Données à traiter
    unsigned short int nbNegatifs; // Compteur des nombres négatifs
    unsigned short int i;          // Indice de parcours

    // TRAITEMENTS
    // () >> Initialiser le compteur >> nbNegatifs
    nbNegatifs = 0;

    // nombres, NB_VALEURS >> Inspecter et traiter sous condition >> nombres, nbNegatifs
    for (i = 0; i < NB_VALEURS; i++)
    {
        if (nombres[i] < 0)
        {
            nbNegatifs++;
            nombres[i] += 1; // Incrémentation des négatifs
        }
    }

    // nbNegatifs >> Afficher le bilan >> (écran)
    cout << "Nombre de valeurs negatives traitees : " << nbNegatifs << endl;
    cout << "Tableau apres mise a jour : ";
    for (i = 0; i < NB_VALEURS; i++)
    {
        cout << nombres[i] << " ";
    }
    cout << endl;

    return 0;
}

 NIVEAU 5 — CEINTURE ORANGE-VERTE (Exercice 5 — Plafond Note : Max 13/20)
================================================================================
MODÈLE OFFICIEL : Modèle 4 Borné OU Modèle 2 + Modèle 4 sur Enregistrement (struct)

TEXTE DE JUSTIFICATION DU CARTOUCHE :
"Traitement conditionné restreint à un sous-ensemble borné (les N premiers éléments)
ou appliqué sur un champ spécifique d'une structure (ex: promo[i].groupeTp).
La boucle 'for' s'arrête strictement à la limite imposée (LIMITE < TAILLE)."

CODE C++ CONFORME (Filtrage d'un tableau d'enregistrements struct Etudiant) :
--------------------------------------------------------------------------------
/*
  Numéro du groupe : 16 (TP4)
  Nom du groupe : Les Flèches de la Précision
  Étudiants : Matéi De Saint Leger, Nicolas Gence, Jules Tison
  Numéro de Kata : Kata 1
  Numéro de l'exercice : 5
  But de l'exercice : Compter le nombre d'étudiants d'un groupe TP donné dans une promo.
  Modèle(s) d'algorithme(s) choisi(s) : Modèle 2 (Saisie TP) + Modèle 4 (Parcours conditionné sur struct)
  Brève justification : Saisie contrôlée du TP recherché puis parcours de tous les
  enregistrements pour compter ceux dont le champ 'tp' correspond.
  Remarques éventuelles : Utilisation de struct conforme au standard IUT Anglet.
*/
#include <iostream>
#include <string>
using namespace std;

// Définition de l'enregistrement
struct Etudiant
{
    string nom;            // Nom de famille
    string prenom;         // Prénom de l'étudiant
    unsigned short int td; // Groupe de TD (1..2)
    unsigned short int tp; // Groupe de TP (1..4)
};

int main(void)
{
    // CONSTANTES
    const unsigned short int EFFECTIF = 5; // Nombre d'étudiants dans la promotion
    const unsigned short int TP_MIN = 1;   // Borne minimale de TP
    const unsigned short int TP_MAX = 4;   // Borne maximale de TP

    // VARIABLES
    Etudiant promo[EFFECTIF] = {
        {"De Saint Leger", "Matei", 2, 4},
        {"Gence", "Nicolas", 2, 4},
        {"Tison", "Jules", 2, 4},
        {"Dupont", "Jean", 1, 1},
        {"Martin", "Alice", 1, 2}
    };
    unsigned short int tpRecherche; // Groupe de TP ciblé
    unsigned short int effectifTp;  // Nombre d'étudiants trouvés dans ce TP
    unsigned short int i;           // Indice de parcours

    // TRAITEMENTS
    // (clavier) >> Saisir-vérifier le TP recherché (Modèle 2) >> tpRecherche
    for ( ; ; )
    {
        cout << "Entrez le groupe de TP a comptabiliser (" << TP_MIN << " a " << TP_MAX << ") : ";
        cin >> tpRecherche;
        if ((tpRecherche >= TP_MIN) && (tpRecherche <= TP_MAX))
        {
            break;
        }
        cout << "Erreur : groupe de TP inexistant !" << endl;
    }

    // () >> Initialiser le compteur >> effectifTp
    effectifTp = 0;

    // promo, EFFECTIF, tpRecherche >> Compter et afficher les étudiants du TP >> effectifTp
    cout << "Etudiants appartenant au TP " << tpRecherche << " :" << endl;
    for (i = 0; i < EFFECTIF; i++)
    {
        if (promo[i].tp == tpRecherche)
        {
            effectifTp++;
            cout << " - " << promo[i].nom << " " << promo[i].prenom << endl;
        }
    }

    // effectifTp >> Afficher le total >> (écran)
    cout << "Total : " << effectifTp << " etudiant(s) dans le TP " << tpRecherche << "." << endl;

    return 0;
}

 NIVEAU 6 — CEINTURE VERTE (Exercice 6 — Plafond Note : Max 15/20)
================================================================================
MODÈLE OFFICIEL : Modèle 5 — Recherche de première occurrence

TEXTE DE JUSTIFICATION DU CARTOUCHE :
"On cherche à savoir si une valeur cible existe dans le tableau ou à connaître
sa première position. Dès que l'élément est trouvé, le parcours DOIT être 
interrompu immédiatement : boucle 'while' conditionnée par un indicateur 
booléen '!trouve' et la borne d'indice '(i < TAILLE)'."

CODE C++ CONFORME :
--------------------------------------------------------------------------------
/*
  Numéro du groupe : 16 (TP4)
  Nom du groupe : Les Flèches de la Précision
  Étudiants : Matéi De Saint Leger, Nicolas Gence, Jules Tison
  Numéro de Kata : Kata 1
  Numéro de l'exercice : 6
  But de l'exercice : Déterminer la position de la première occurrence d'une cible.
  Modèle(s) d'algorithme(s) choisi(s) : Modèle 5 (Recherche de première occurrence)
  Brève justification : Arrêt obligatoire dès la première trouvaille. Boucle while
  avec drapeau booléen 'trouve' et borne de dépassement de tableau.
  Remarques éventuelles : AUCUN break dans une boucle for (règle stricte des profs).
*/
#include <iostream>
using namespace std;

int main(void)
{
    // CONSTANTES
    const unsigned short int TAILLE = 7; // Nombre d'éléments du tableau

    // VARIABLES
    int tab[TAILLE] = {14, 25, 8, 42, 19, 42, 33}; // Tableau source
    int valeurCible;                               // Valeur recherchée
    bool trouve;                                   // Indicateur de présence (Modèle 5)
    unsigned short int i;                          // Indice de parcours

    // TRAITEMENTS
    // (clavier) >> Saisir la valeur cible >> valeurCible
    cout << "Entrez la valeur a rechercher dans le tableau : ";
    cin >> valeurCible;

    // () >> Initialiser l'état de la recherche >> trouve, i
    trouve = false;
    i = 0;

    // tab, TAILLE, valeurCible >> Chercher la première occurrence >> trouve, i
    while ((!trouve) && (i < TAILLE))
    {
        if (tab[i] == valeurCible)
        {
            trouve = true; // Trouvé : la boucle s'arrêtera au prochain test
        }
        else
        {
            i++; // On avance à la case suivante seulement si non trouvé
        }
    }

    // trouve, i >> Exploiter le résultat de la recherche >> (écran)
    if (trouve)
    {
        cout << "Valeur " << valeurCible << " trouvee en premiere occurrence a l'indice : " << i << endl;
    }
    else
    {
        cout << "Valeur " << valeurCible << " absente du tableau." << endl;
    }

    return 0;
}

 NIVEAU 7 — CEINTURE BLEUE (Exercice 7 — Plafond Note : Max 16/20)
================================================================================
MODÈLE OFFICIEL : Modèle 5 à Rebours OU Modèle 1 + Parcours borné à la moitié

TEXTE DE JUSTIFICATION DU CARTOUCHE :
"Cas A (Dernière occurrence) : Recherche à rebours en partant du dernier indice
(TAILLE - 1) vers 0. La première valeur rencontrée à reculons est mathématiquement
la dernière occurrence du tableau.
Cas B (Inversion sur place) : Échange symétrique de tab[i] et tab[N - 1 - i] pour
i allant strictement de 0 à (N / 2) - 1. Si on dépassait la moitié, on ré-inverserait
le tableau pour revenir à l'état initial !"

CODE C++ CONFORME (Inversion de tableau sur place — In-Place Swap) :
--------------------------------------------------------------------------------
/*
  Numéro du groupe : 16 (TP4)
  Nom du groupe : Les Flèches de la Précision
  Étudiants : Matéi De Saint Leger, Nicolas Gence, Jules Tison
  Numéro de Kata : Kata 1
  Numéro de l'exercice : 7
  But de l'exercice : Inverser un tableau sur place sans créer de deuxième tableau.
  Modèle(s) d'algorithme(s) choisi(s) : Modèle 1 (Échange) sur parcours borné à la moitié
  Brève justification : Échange symétrique tab[i] et tab[N-1-i] de 0 à (N/2)-1.
  S'arrêter strictement à la moitié pour ne pas annuler l'inversion.
  Remarques éventuelles : Fonctionne pour les tailles paires et impaires.
*/
#include <iostream>
using namespace std;

int main(void)
{
    // CONSTANTES
    const unsigned short int EFFECTIF = 7; // Nombre d'éléments (taille impaire ici)

    // VARIABLES
    int tab[EFFECTIF] = {1, 2, 3, 4, 5, 6, 7}; // Tableau à inverser
    unsigned short int i;                      // Indice de parcours
    int temporaire;                            // Tampon d'échange (Modèle 1)
    const unsigned short int BORNE_MOITIE = EFFECTIF / 2; // Limite stricte

    // TRAITEMENTS
    // tab, BORNE_MOITIE >> Inverser le tableau sur place >> tab
    for (i = 0; i < BORNE_MOITIE; i++)
    {
        // Échanger tab[i] avec son symétrique tab[EFFECTIF - 1 - i]
        temporaire = tab[i];
        tab[i] = tab[EFFECTIF - 1 - i];
        tab[EFFECTIF - 1 - i] = temporaire;
    }

    // tab >> Afficher le tableau inversé >> (écran)
    cout << "Tableau inverse sur place : ";
    for (i = 0; i < EFFECTIF; i++)
    {
        cout << tab[i] << " ";
    }
    cout << endl;

    return 0;
}

 NIVEAU 8 — CEINTURE MARRON (Exercice 8 — Plafond Note : Max 18/20)
================================================================================
MODÈLE OFFICIEL : Modèle 5 (Recherche d'une anomalie avec sortie anticipée) / Deux curseurs

TEXTE DE JUSTIFICATION DU CARTOUCHE :
"Pour vérifier une propriété universelle ('Le tableau est-il trié ?', 'Le mot est-il
un palindrome ?', 'Les signes alternent-ils ?'), on recherche la PREMIÈRE ANOMALIE
qui contredit la règle. Dès qu'une anomalie est trouvée, on s'arrête (la propriété
est fausse). Si la boucle se termine sans anomalie, la propriété est vraie."

CODE C++ CONFORME (Vérification de l'alternance stricte des signes) :
--------------------------------------------------------------------------------
/*
  Numéro du groupe : 16 (TP4)
  Nom du groupe : Les Flèches de la Précision
  Étudiants : Matéi De Saint Leger, Nicolas Gence, Jules Tison
  Numéro de Kata : Kata 1
  Numéro de l'exercice : 8
  But de l'exercice : Vérifier si les éléments du tableau alternent strictement de signe.
  Modèle(s) d'algorithme(s) choisi(s) : Modèle 5 (Recherche de la 1re anomalie)
  Brève justification : On recherche deux cases consécutives de même signe (tab[i]*tab[i+1] >= 0).
  Arrêt immédiat dès la 1re infraction constatée.
  Remarques éventuelles : La boucle s'arrête à TAILLE - 2 pour éviter tab[i+1] hors bornes.
*/
#include <iostream>
using namespace std;

int main(void)
{
    // CONSTANTES
    const unsigned short int TAILLE = 6; // Nombre d'éléments du tableau

    // VARIABLES
    int tab[TAILLE] = {5, -3, 8, -2, 9, -4}; // Tableau respectant l'alternance
    bool anomalieTrouvee;                    // Indicateur d'infraction à la règle
    unsigned short int i;                    // Indice de parcours

    // TRAITEMENTS
    // () >> Initialiser la recherche d'anomalie >> anomalieTrouvee, i
    anomalieTrouvee = false;
    i = 0;

    // tab, TAILLE >> Rechercher une violation d'alternance >> anomalieTrouvee
    while ((!anomalieTrouvee) && (i < (TAILLE - 1)))
    {
        // Deux nombres ont le même signe si leur produit est >= 0 (ou si l'un est 0)
        if ((tab[i] > 0 && tab[i + 1] > 0) || (tab[i] < 0 && tab[i + 1] < 0) || (tab[i] == 0) || (tab[i + 1] == 0))
        {
            anomalieTrouvee = true; // Anomalie détectée : on stoppe
        }
        else
        {
            i++;
        }
    }

    // anomalieTrouvee >> Afficher le verdict >> (écran)
    if (!anomalieTrouvee)
    {
        cout << "Succes : le tableau respecte une alternance stricte des signes !" << endl;
    }
    else
    {
        cout << "Echec : alternance rompue a l'indice " << i << " (" << tab[i] << " et " << tab[i + 1] << ")." << endl;
    }

    return 0;
}


================================================================================
 NIVEAU 9 — CEINTURE NOIRE (Exercice 9 — Note Maximale : 20/20)
================================================================================
MODÈLE OFFICIEL : Double Modèle 5 imbriqué (Inclusion) OU Tri Pair-Impair (Défi)

TEXTE DE JUSTIFICATION DU CARTOUCHE (Inclusion d'un tableau secret dans decod) :
"Pour vérifier que chaque élément du sous-ensemble 'secret' est présent dans 
le tableau 'decod', on utilise une boucle externe (Modèle 5) qui s'arrête dès
qu'un élément secret est ABSENT de decod. La présence de chaque élément est
elle-même déterminée par une boucle interne de recherche (Modèle 5)."

CODE C++ CONFORME (Inclusion de secret[TAILLE_SECRET] dans decod[TAILLE_DECOD]) :
--------------------------------------------------------------------------------
/*
  Numéro du groupe : 16 (TP4)
  Nom du groupe : Les Flèches de la Précision
  Étudiants : Matéi De Saint Leger, Nicolas Gence, Jules Tison
  Numéro de Kata : Kata 1
  Numéro de l'exercice : 9 (Ceinture Noire)
  But de l'exercice : Déterminer si toutes les valeurs du tableau secret sont dans decod.
  Modèle(s) d'algorithme(s) choisi(s) : Double Modèle 5 imbriqué (Recherche d'anomalie d'inclusion)
  Brève justification : Boucle externe stoppée dès qu'un élément de secret n'est pas trouvé
  dans decod. Boucle interne stoppée dès que l'élément courant est trouvé dans decod.
  Remarques éventuelles : Double sortie anticipée pour une complexité optimale.
*/
#include <iostream>
using namespace std;

int main(void)
{
    // CONSTANTES
    const unsigned short int TAILLE_SECRET = 3;
    const unsigned short int TAILLE_DECOD = 8;

    // VARIABLES
    int secret[TAILLE_SECRET] = {12, 42, 7};
    int decod[TAILLE_DECOD]   = {5, 7, 19, 12, 33, 42, 88, 1};

    bool inclusionValide; // Vrai si tous les secrets sont dans decod
    unsigned short int indSecret; // Curseur de la boucle externe
    bool elementCourantTrouve;    // Drapeau de la boucle interne
    unsigned short int indDecod;  // Curseur de la boucle interne

    // TRAITEMENTS
    // () >> Initialiser l'état d'inclusion >> inclusionValide, indSecret
    inclusionValide = true;
    indSecret = 0;

    // secret, decod >> Vérifier l'inclusion de secret dans decod >> inclusionValide
    while (inclusionValide && (indSecret < TAILLE_SECRET))
    {
        // Recherche de secret[indSecret] dans decod (Modèle 5 interne)
        elementCourantTrouve = false;
        indDecod = 0;

        while ((!elementCourantTrouve) && (indDecod < TAILLE_DECOD))
        {
            if (decod[indDecod] == secret[indSecret])
            {
                elementCourantTrouve = true;
            }
            else
            {
                indDecod++;
            }
        }

        // Si l'élément courant n'existe pas dans decod, l'inclusion échoue
        if (!elementCourantTrouve)
        {
            inclusionValide = false; // Arrêt immédiat de la boucle externe !
        }
        else
        {
            indSecret++;
        }
    }

    // inclusionValide >> Afficher le verdict final >> (écran)
    if (inclusionValide)
    {
        cout << "Ceinture Noire Validee : Toutes les valeurs de 'secret' sont bien presentes dans 'decod' !" << endl;
    }
    else
    {
        cout << "Echec : L'element secret[" << indSecret << "] = " 
             << secret[indSecret] << " est absent de 'decod'." << endl;
    }

    return 0;
}

 CODE BONUS : LE DÉFI INDIVIDUEL (Tri Pair-Impair par Transposition)
================================================================================
Ce modèle a été le sujet du Défi Individuel officiel (Moodle #24184).
Si l'exercice 9 demande de trier un tableau sans utiliser 'sort()' :

void triPairImpair(int tab[], unsigned short int taille)
{
    bool estTrie = false;
    unsigned short int i;
    int temporaire;

    while (!estTrie)
    {
        estTrie = true; // On suppose le tableau trié avant la double passe

        // Passe 1 : Indices pairs (i = 0, 2, 4...)
        for (i = 0; i + 1 < taille; i += 2)
        {
            if (tab[i] > tab[i + 1])
            {
                temporaire = tab[i];
                tab[i] = tab[i + 1];
                tab[i + 1] = temporaire;
                estTrie = false; // Une permutation a eu lieu
            }
        }

        // Passe 2 : Indices impairs (i = 1, 3, 5...)
        for (i = 1; i + 1 < taille; i += 2)
        {
            if (tab[i] > tab[i + 1])
            {
                temporaire = tab[i];
                tab[i] = tab[i + 1];
                tab[i + 1] = temporaire;
                estTrie = false; // Une permutation a eu lieu
            }
        }
    }
}

1. "Pourquoi avoir utilisé 'while' et non pas 'for' dans votre recherche ?"
-> RÉPONSE ETCHEVERRY : "Parce qu'il s'agit d'un parcours partiel dont le nombre 
   d'itérations dépend de la position de la cible. Une boucle 'for' sous-entend 
   que l'on va systématiquement jusqu'au bout, et y insérer un 'break' casse la 
   sémantique de la structure. Le 'while' avec booléen est le standard académique."

2. "Pourquoi déclarer vos indices en 'unsigned short int' ?"
-> RÉPONSE ETCHEVERRY : "Parce qu'un indice de tableau ne peut mathématiquement 
   pas être négatif et que la taille du problème est inférieure à 65 535. Cela 
   évite les dépassements de capacité, économise la mémoire et documente le 
   domaine de validité sémantique de la variable."

3. "Pourquoi borner l'inversion de tableau à (TAILLE / 2) ?"
-> RÉPONSE ETCHEVERRY : "Si on parcourait tout le tableau jusqu'à TAILLE - 1, 
   chaque paire d'éléments serait échangée une deuxième fois dans la seconde 
   moitié, ce qui remettrait le tableau exactement dans son ordre de départ !"
