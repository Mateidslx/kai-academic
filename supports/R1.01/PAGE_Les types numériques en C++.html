Types numériques en C++

Tailles usuelles, plages de valeurs et rappels de vocabulaire.

Nombres signés / non signés

Les valeurs numériques peuvent comporter un signe ou pas. Pour représenter :

  • les nombres sans signe, on utilise l’attribut unsigned ;
  • les nombres avec signe, on utilise l’attribut signed.
Les caractères

Le type char est destiné à représenter un caractère (par exemple : ?, *, %…).

Chaque caractère est représenté par un code numérique nommé code ASCII. La table contient 256 symboles : lettres, chiffres, ponctuation, espaces, etc. Le dessin et le codage numérique sont définis par la norme ASCII.

Type de base Taille en octet
unsigned char 1
(signed) char 1

Remarque : l’attribut signed est la valeur par défaut ; char et signed char sont équivalents.
