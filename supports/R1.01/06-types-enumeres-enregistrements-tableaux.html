    Introduction

    Problème de départ

    Jusqu'à maintenant, les programmes que nous avons écrits ont manipulé des informations simples : des entiers, des nombres à virgule, des chaînes de caractères etc : 

    
                string nom; // le nom de l'étudiant
                float moyenne ; // la moyenne de l' étudiant
                bool estBoursier; // indique si l'étudiant est boursier

    Beaucoup de problèmes nécessitent néanmoins de manipuler des informations plus complexes qui ne peuvent être représentées avec des types de base : 

    
                ???? noteDeMusique; // une note de musique (do, ré...)
                ???? adresseIUT; // l'adresse complète de l'IUT
                ???? grilleDeMorpion; // une grille de morpion vierge

    Construire de nouveaux types de données

    Dans ce cours, nous allons étudier quelques techniques qui permettent à un programmeur de :

    • fabriquer ses propres types de données ;
    • déclarer ensuite des variables qui seront typées avec ces nouveaux types.

    De manière plus précise, nous aborderons les notions :

    • de type énuméré ;
    • d'enregistrement ;
    • de tableau.

    Types énumérés

    Intérêt des types énumérés

    Un type énuméré est un type défini à partir d'une liste de valeurs.

    Les types énumérés présentent un intérêt pour représenter des informations ayant une liste de valeurs finie :

    • Mois de l'année : janvier, février, mars...
    • Notes de musique : do, ré, mi...
    • Cartes à jouer : valet, as, roi, dame...
    • État civil : célibataire, marié, veuf...

    Codage en C++

    Les types énumérés sont définis au moyen du mot clé enum en suivant la syntaxe suivante : 

    
                  enum nomDuType { valeur1 , valeur2 , ... , valeurN };

    Exemple : 

    
                  enum UnJour {lundi, mardi, mercredi, jeudi, vendredi, samedi, dimanche};

    Construire un nouveau type énuméré et déclarer des variables associées

    Une fois le type énuméré défini, il est possible de déclarer des variables de ce type comme on le fait habituellement : 

    
                  // Définition du type UnJour
                  enum UnJour {lundi, mardi, mercredi, jeudi, vendredi, samedi, dimanche};
  
                  // Déclaration de deux variables de type UnJour
                  UnJour premierJourSemaine = lundi;
                  UnJour dernierJourSemaine = dimanche;

    Remarque : lundi et dimanche sont des valeurs possibles pour des variables de type UnJour : il ne faut pas les délimiter avec des guillemets ("lundi") car ce ne sont pas des chaînes de caractères mais des valeurs de type UnJour.

    Représentation du type énuméré en C++

    Une énumération définit en fait des constantes entières appelées ici lundi, mardi, mercredi, jeudi, vendredi, samedi, dimanche : 

    
                  enum UnJour {lundi, mardi, mercredi, jeudi, vendredi, samedi, dimanche};

    Par défaut, ces constantes prennent les valeurs entières à partir de 0.

    Dans l'exemple ci-dessus, lundi vaut 0 et dimanche vaut 6 :

    Contrôler les constantes représentant les valeurs du type énuméré

    On peut imposer les valeurs voulues pour les constantes du type énumératif, si cela est jugé d'intérêt pour le programme élaboré : 

    
                  enum UnJour {lundi=1, mardi, mercredi, jeudi, vendredi, samedi, dimanche};

    Avec cette définition, la valeur lundi est associée à la constante entière 1, la valeur mardi est associée à la constante entière 2... et la valeur dimanche est associée à la constante entière 7.

    Autre exemple : 

    
                  enum UnPoids {leger=1, moyen=5, lourd=10};

    Ici, la valeur leger est associée à la constante entière 1, la valeur moyen est associée à la constante entière 5 et la valeur dimanche est associée à la constante entière 10.

    Comparaison sur des types énumérés : autorisée

    Les valeurs des types énumérés étant définies comme des constantes entières il est possible de les comparer entre elles :

                else
                {
                    cout << "Bon courage !" << endl;
                }

                         if (jourCourant >= 4 && jourCourant <= 6)

    Enregistrements

    Intérêt des enregistrements

    Les enregistrements[1] permettent de regrouper des informations qui peuvent être hétérogènes au sein d'un même type.

      Informations hétérogènes : Définition

    Des informations hétérogènes sont des informations ayant des types différents.

    Exemple : Définition d'un type adresse regroupant les données suivantes :

    • un numéro de rue (sous forme d'entier) ;
    • un nom de rue (sous forme de chaine) ;
    • un code postal (sous forme d'entier ou de chaine) ;
    • un nom de ville (sous forme de chaine).
    [1] appelés aussi record, n-uplet ou tuple

    Codage en C++

    Un enregistrement est défini au moyen du mot clé struct en précisant le nom et le type de toutes les informations qui le compose : 

    
                struct UneAdresse
                {
                   unsigned short int numRue ; // numéro de rue
                   string nomRue ; // nom de la rue
                   unsigned int codePostal ; // code postal de la ville
                   string nomVille ; // nom de la ville
                };

    Accès aux attributs

    L'accès aux informations composant un enregistrement est réalisé au moyen de la notation pointée (cf. ligne 17 ci-dessous) : 

    
                // Définition du type UneAdresse
                struct UneAdresse
                {
                   unsigned short int numRue ; // numéro de rue
                   string nomRue ; // nom de la rue
                   unsigned int codePostal ; // code postal de la ville
                   string nomVille ; // nom de la ville
                };

                UneAdresse adresseIut ; // L'adresse de l'IUT

                // Initialisation de l'adresse de l'IUT >> adresseIut
                ...
                ...

                // adresseIut >> Afficher la ville où se trouve l'IUT >> écran
                cout << adresseIut.nomVille;

    Initialisation des attributs

    Les attributs d'un enregistrement peuvent être initialisés :

    • individuellement, n'importe quand : 
      
                        UneAdresse adresseIut ;
                        adresseIut.numRue = 2;
                        adresseIut.nomRue = "allée du Parc Montaury";
                        adresseIut.codePostal = 64600;
                        adresseIut.nomVille = "Anglet";
    • globalement, à la déclaration : 
      
                        UneAdresse adresseIut = {2,"allée du Parc Montaury", 64600,"Anglet"};

    Tableaux

    Définitions

      Tableaux : Définition

    Un tableau est une structure à accès direct regroupant généralement des données homogènes[1].

      Informations homogènes : Définition

    Des informations homogènes sont des informations ayant toutes le même type[2].

      Structure à accès direct : Définition

    Une structure à accès direct regroupe un ensemble d'éléments ordonnés et propose des mécanismes permettant d'accéder à chaque élément directement sans passer par ceux qui le précèdent.

    [1] C'est le cas en C++ et Java par exemple mais ce n'est pas le cas en PHP ou Cobol.
    [2] Si les types sont différents on parlera d'informations hétérogènes.

    Structure d'un tableau

    Un tableau est généralement vu comme une suite de cases[1] situées dans un espace mémoire contiguë.

    Dans le cas d'un tableau homogène, les cases sont toutes de même taille et la taille de chaque case est définie en fonction du type de donnée qu'elle contient.

    Un tableau peut contenir quasiment tout type d'élément :

    • des données de type simple : entiers, nombre à virgule, caractère, chaine... [2];
    • des pointeurs[3];
    • des types énumérés ;
    • des enregistrements ;
    • des objets ;
    • des tableaux.
    [1] appelées aussi cellules.
    [2] la taille d'une case du tableau est alors le nombre d'octets sur lequel la donnée est codée.
    [3] variables contenant une adresse mémoire.

    Dimension d'un tableau

    • Lorsque le tableau est composé de données de type simple, on parle de tableau à une dimension ou de vecteur.
    • Lorsque le tableau contient lui-même d'autres tableaux on parle de tableau multimensionnel.

    un tableau à 1 dimension
    composé de 3 cases

    un tableau à 2 dimensions
    (appelé matrice ou table)
    composé de 3 x 3 cases

    un tableau à 3 dimensions
    composé de 3 x 3 x 3 cases

    Tableau statique / dynamique

    • Lorsque la taille du tableau est fixe, elle est définie une fois pour toute à la déclaration du tableau On parle alors de tableau statique.
    • Lorsque la taille du tableau évolue en cours d'exécution, on parle de tableau dynamique.

    Dans ce cours, nous n'aborderons que les tableaux statiques.

    Déclaration d'un tableau statique à 1 dimension

    La syntaxe pour déclarer un tableau est la suivante :

    typeDesElements nomDuTableau [nombreDeCases];

    • typeDesElements définit le type d'élément stocké dans le tableau (rappel : En C++, un tableau est composé uniquement d'éléments de même type, c'est une structure homogène) ;
    • nomDuTableau est le nom du tableau. Le nom du tableau suit les mêmes règles qu'un nom de variable (nom parlant, sans accents ni espaces) ;
    • [nombreDeCases] une constante entière qui détermine le nombre de cases qui composent le tableau.

    Exemple : 

    
                float notes [10]; // Déclaration d'un tableau de 10 notes

    Tableau statique : contrainte d'usage

    Étant donné qu'un tableau est composé d'un nombre fixe d'éléments homogènes, la taille d'un tableau statique est fixée dès sa déclaration.

    Le programme qui suit est donc incorrect : 

    
                // Même si le compilateur ne génère aucune erreur, cette approche est INTERDITE

                unsigned int tailleTab ; // Taille du tableau (sans valeur prédéfinie)
                float notes [tailleTab]; // un tableau de taille ALEATOIRE !

                cout << " Entrez le nombre de cases du tableau de notes : " ;
                cin >> tailleTab ; /* Suite à la saisie de tailleTab, le tableau notes n'est pas  
                                      redimensionné car ce n'est pas un tableau dynamique ! */

    Saisir la taille d'un tableau statique

    Si on souhaite saisir la taille du tableau au clavier, il est nécessaire de déclarer le tableau après la saisie : 

    
                unsigned int tailleTab ; // Taille du tableau

                cout << " Entrez le nombre de cases du tableau : " ;
                cin >> tailleTab ;

                // Déclaration d'un tableau de tailleTab cases :
                float notes [tailleTab]; /* Ici la valeur de tailleTab est définie, la
                                            déclaration du tableau est donc correcte. */

    Taille prédéfinie : bonne pratique

    Lorsque la taille d'un tableau statique est prédéfinie, une bonne pratique consiste à définir cette taille sous forme de constante : 

    
                const unsigned short int NB_CASES = 10; // Taille du tableau de notes
                float notes [NB_CASES]; // Le tableau contenant les notes

    Le fait de déclarer la taille du tableau sous forme de constante :

    • garantit que la taille du tableau est fixe ;
    • améliore la lisibilité du code en indiquant que le tableau est statique (puisque sa taille est constante) ;
    • permet de ré-exploiter facilement la taille du tableau lors des algorithmes de parcours.

    Taille en mémoire

    La taille d'un tableau est obtenue en multipliant la taille mémoire d'un élément par le nombre de cases du tableau :

    Déclaration du tableau Taille occupée mémoire
    double notes [10]; 10 cases x 8 octets = 80 octets
    int nbEtudiantsParTd [4]; 4 cases x 4 octets = 16 octets
    char alphabet [26]; 26 cases x 1 octet = 26 octets

    Accès aux éléments d'un tableau

    Chaque case d'un tableau porte un numéro appelé indice.

    Pour accéder à un élément d'un tableau, le programmeur doit préciser le nom du tableau, suivi de l'indice de l'élément auquel il souhaite accéder entre crochets :

    nomDuTableau [ indice ]

    Propriétés des indices

    On retiendra que :

    • L'indice du premier élément du tableau est 0 ;
    • Un indice est toujours positif ou nul ;
    • L'indice du dernier élément du tableau est égal au nombre de cases - 1

    Ainsi, on accédera au 5ème élément d'un tableau notes en écrivant notes[4]

    Initialisation d'un tableau (1/2)

    Un tableau peut être initialisé en affectant successivement une valeur à chaque élément : 

    
                const unsigned int NB_CASES = 10; // Taille du tableau
                float notes [NB_CASES]; // Déclaration du tableau de notes

                // Initialisation de chaque élément du tableau
                notes [0] = 9;
                notes [1] = 11.5;
                ...
                ...
                notes [8] = 7;
                notes [9] = 15.5;

    Initialisation d'un tableau (2/2)

    Un tableau peut également être initialisé globalement à la déclaration : 

    
                const unsigned int NB_CASES = 10; // Taille du tableau
                float notes [NB_CASES] = {9, 11.5, 6, 14.5, 10, 13, 11.5, 18, 7, 15.5};

    Attention cependant :

    • Le nombre de valeurs entre accolades ne doit pas être supérieur au nombre d'éléments du tableau ;
    • Les valeurs entre accolades doivent être des constantes (l'utilisation de variables provoquera une erreur du compilateur) ;
    • Il doit y avoir au moins une valeur entre accolades ;

    • Si le nombre de valeurs entre accolades est inférieur au nombre de cases du tableau, les derniers éléments sont initialisés à 0. Ainsi, l'instruction ci-contre permet d'initialiser toutes les cases du tableau à zéro. 

      
                                        const unsigned int NB_CASES = 10;
                                        float notes [NB_CASES] = {0};

    Tableaux multidimensionnels : représentation

    Les tableaux multidimensionnels sont des tableaux qui contiennent des tableaux.

    Par exemple le tableau à deux dimensions suivant (3 lignes, 4 colonnes), est en fait un tableau comportant 3 cases, chaque case contenant un autre tableau de 4 cellules :

    Les tableaux à deux dimensions peuvent par exemple être utilisés pour représenter un échiquier, une grille de morpion, un jeu de bataille navale...

    Tableaux multidimensionnels : déclaration

    La syntaxe pour déclarer un tableau multidimensionnel est la suivante :

    typeDesElements nomDuTableau [nbCasesDimension1] [nbCasesDimension2] ... [nbCasesDimensionN];

    • Le nombre de cases de chaque dimension est défini entre crochets ;
    • En théorie, le nombre de dimensions n'est pas limité.

    Exemple : Un tableau d'entiers positifs à deux dimensions (3 lignes, 4 colonnes) se définira de la manière suivante : 

    
                        unsigned int matrice [3][4] ;

    Tableaux multidimensionnels : accès aux éléments

    L'accès aux éléments d'un tableau multidimensionnel est réalisé en donnant les indices permettant de désigner la case au travers de chaque dimension.

    Ainsi, tab [ 1 ] [ 2 ] désigne la case située :

    • à la ligne 1, colonne 2 (vue matricielle) ;

    Tableaux multidimensionnels : initialisation (1/2)

    L'initialisation d'un tableau multidimensionnel peut être réalisé en affectant une valeur à chaque case qui le compose : 

    
                // Déclaration du tableau
                unsigned int matrice [3][4] ; 

                // Initialisation du tableau avec des valeurs
                matrice [1][0] = 1; // initialisation de la ligne 1 , colonne 0
                matrice [0][1] = 2; // initialisation de la ligne 0 , colonne 1
                matrice [2][2] = 3; // initialisation de la ligne 2 , colonne 2

    Tableaux multidimensionnels : initialisation (2/2)

    Comme pour les tableaux unidimensionnels, il est possible d'initialiser un tableau multidimensionnel globalement à la déclaration : 

    
                unsigned int matrice [3][4] = {1, 2, 3, 4, 5, 6, 7, 8, 9, 1, 2, 3} ;
