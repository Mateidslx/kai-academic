✓ Rappel de points importants

Au-delà de produire un code fonctionnel, votre but consistera surtout à :

  • produire un code fidèle aux algorithmes élaborés en TD ;
  • appliquer toutes les bonnes pratiques de programmation mises en avant dans les tutoriels vidéos vus jusqu’à maintenant.
Critères de qualité à prendre en compte à ce stade d’avancement
  1. Écrire progressivement et compiler à chaque étape.
  2. Utiliser des noms significatifs pour variables/constantes.
  3. Respecter les conventions de nommage.
  4. Choisir des types précis et adaptés.
  5. Documenter par des commentaires utiles.
  6. Structurer en blocs alignés sur l’algorithme.
  7. Garder la correspondance code ↔ algorithme.
  8. Toujours indenter.
  9. Écrire les structures en deux étapes (squelette → remplissage).
  10. Toujours délimiter par des accolades (même pour une seule instruction).

⚠️ Attention

Aucune aide ne vous sera fournie en TP si vous n’êtes pas en mesure de montrer l’algorithme sur lequel vous vous appuyez pour élaborer votre code !

Ne codez jamais un exercice sans avoir, au préalable, réalisé l’algorithme correspondant. Même en TP, si vous devez écrire un code dont vous n’avez pas l’algorithme, lâchez le clavier, prenez une feuille et un crayon et concevez votre solution sur papier puis faites-la valider par votre enseignant.

📌 Important

Un exercice est jugé terminé si vous êtes en mesure :

  1. de fournir l’algorithme correspondant ;
  2. de fournir le code correspondant ;
  3. d’expliquer comment les bonnes pratiques de programmation vues jusqu’à maintenant ont été appliquées dans le code ;
  4. de répondre à n’importe quelle question posée par votre enseignant, que ce soit sur l’algorithme ou sur le code.
