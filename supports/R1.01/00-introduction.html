    Origine du mot

    Le mot algorithme vient du nom du mathématicien perse Al-Khwârizmı̂ né dans les années 780.

    Al-Khwârizmı̂ est entre autres connu pour avoir rédigé un ouvrage nommé Hisab El-Jabr Wa Al-Muqabala. Le terme algèbre vient d’ailleurs du titre de cet ouvrage.

    Dans cet ouvrage Al-Khwârizmı̂, décrit une méthode pour résoudre les équations du 1er et du 2nd degré.

    Quelques exemples d'algorithmes dans la vie quotidienne...

    Le cas de la recette de cuisine...

      Rappel

    Un algorithme est la description d'une solution détaillant des opérations simples à enchaîner pour résoudre un problème spécifique.

    Une recette de cuisine s'apparente, par certains côtés, à un algorithme...

    Problème : Comment faire une omelette aux cèpes ?

    Description de la solution sous forme d'opérations à enchaîner :

    1. Casser les œufs dans un saladier
    2. Ajouter un peu de sel
    3. Battre les œufs à l’aide d’une fourchette
    4. Faire cuire les cèpes à feu doux dans une poêle
    5. ...

      Quand vous suivez une recette de cuisine, vous exécutez un algorithme.

    Guider un touriste perdu...

      Rappel

    Un algorithme est la description d'une solution détaillant des opérations simples à enchaîner pour résoudre un problème spécifique.

    Quand vous indiquez son chemin à quelqu'un qui est perdu, vous lui donnez un algorithme...

    Problème : Comment rejoindre la gare ?

    Description de la solution sous forme d'opérations à enchaîner :

    1. Continuez tout droit sur environ 100 mètres
    2. Tournez ensuite à gauche
    3. Lorsque vous atteignez le poste de police bifurquez à droite
    4. Parcourez environ 200 mètres pour atteindre la gare

      Quand vous guidez un touriste, vous concevez un algorithme.

    Un exemple d'algorithme en informatique...

    Diviser deux nombres...

      Rappel

    Un algorithme est la description d'une solution détaillant des opérations simples à enchaîner pour résoudre un problème spécifique.

    Un exemple (non formalisé) d'un algorithme "simple" dans le domaine informatique :

    Problème : Concevoir un programme qui permet de diviser deux nombres saisis au clavier.

    Description de la solution sous forme d'opérations à enchaîner :

    1. Saisir au clavier le dividende
    2. Saisir au clavier le diviseur
    3. Calculer le résultat de la division :
      résultat = dividende ÷ diviseur
    4. Afficher le résultat

    Et si le diviseur égale 0 ? L'algorithme est "faux" ?

      Nous verrons l'importance de cerner le contexte dans lequel un algorithme s'exécutera : La solution décrite par un algorithme peut être "valide" dans un contexte donné et "invalide" dans un autre.

    Les formalismes algorithmiques

    Quel formalisme pour décrire un algorithme ?

      Rappel

    Un algorithme est la description d'une solution détaillant des opérations simples à enchaîner pour résoudre un problème spécifique.

    Question : Peut-on décrire des solutions algorithmiques en français comme pour une recette de cuisine

    Le français comme langage algorithmique ?

    Lorsque vous suivez et réalisez une recette culinaire rédigée par votre grand-mère, le plat obtenu n'a jamais exactement le même goût que chez votre grand-mère... Pourquoi ?

    En partie parce que la recette est rédigée en français et comporte des imprécisions :

    • ajouter une "pincée" de sel ;
    • verser un "soupçon" d'armagnac ;
    • compléter avec une "poignée" de riz ;
    • laisser mijoter "environ" 3 heures ;
    • ...

    Le problème des langages "imprécis"...

    Aucune imprécision ne peut être tolérée dans un algorithme car l'algorithme va être mis en œuvre par une machine et une machine ne sait pas exécuter des instructions imprécises.

      Il faut donc utiliser un langage de description extrêmement précis qui permettra de décrire une solution claire et non ambigüe.

    Quelles sont les solutions possibles ?

    Types de langages algorithmiques

    Il existe deux types de langage pour décrire des algorithmes :

    • les langages à base de pseudo-code : il s’agit de langages composés d’un ensemble restreint de mots : Début, Fin, Lire, Ecrire, Si...alors, Répéter, ...
    • les langages graphiques : ils reprennent le même principe que les langages à base de pseudo-code mais les mots autorisés sont remplacés par des symboles graphiques.

    Pseudo-code / langage graphique : Exemple

    Un même algorithme formalisé avec du pseudo-code et avec un langage graphique :

    Algorithme calculRemise

    Debut
       Lire brut
       Si brut > 1000 Alors
          montant_remise ← brut × 0.05
       Sinon
          montant_remise ← 0
       finSi
       Ecrire montant_remise
    Fin

    A noter : il existe plusieurs langages de type pseudo-code et il existe plusieurs langages graphiques pour formaliser des algorithmes.

    Qu'est-ce que l'algorithmique ?

    L'algorithmique est une discipline dans laquelle on étudie :

    • des méthodes pour concevoir des algorithmes ;
    • des techniques pour évaluer l'efficacité d'un algorithme; [1]
    • des algorithmes "modèles" qui peuvent être utilisés pour résoudre efficacement et rapidement des problèmes fréquemment rencontrés en programmation. [2]
    [1] Il s'agira de calculer la complexité d'un algorithme
    [2] Rechercher un élément dans une liste, trier les valeurs stockées dans un fichier, compter dans un tableau combien de valeurs vérifient une propriété...

    Algorithmique... et programmation

    La science algorithmique est au cœur de toutes les techniques de programmation. Un programmeur doit maı̂triser les techniques fondamentales de l'algorithmique pour écrire des programmes de qualité.

    L'algorithmique est donc le permis de conduire du programmeur. Sans elle, le développeur encourt le risque de produire des programmes qui ne tiennent pas la route

    Pourquoi étudier l'algorithmique (1/3) ?

    Maı̂triser l'algorithmique, c'est :

    • Savoir concevoir les différentes briques composant un programme ;
    • Savoir manier la structure logique d'un programme; [1]
    • Maı̂triser un formalisme permettant de décrire des solutions qui pourront être mises en œuvre par des programmes, quelque soit le langage de programmation utilisé.
    [1] Cette structure logique est présente quelque soit le langage de programmation considéré.

    Pourquoi étudier l'algorithmique (2/3) ?

    Maı̂triser l'algorithmique, c'est aussi :

    • Savoir séparer les problèmes de conception des problèmes techniques pour être en mesure de traiter une difficulté à la fois lorsque les choses se compliquent.
    • Maı̂triser des techniques de conception réutilisables et efficaces permettant de développer des programmes de qualité rapidement.
    • Savoir relever le défi suivant : Comment combiner astucieusement les opérations basiques d'une machine pour résoudre un problème complexe...
