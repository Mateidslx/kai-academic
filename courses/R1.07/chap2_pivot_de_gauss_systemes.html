Chapitre 2 : Systèmes d'Équations Linéaires & Algorithme du Pivot de Gauss

Écriture matricielle Ax = B, opérations élémentaires sur les lignes (combinaison, échange, multiplication non nulle), échelonnement et résolution par substitution arrière.

1. Formulation Matricielle d'un Système Linéaire

Un système de $n$ équations linéaires à $p$ inconnues $x_1, x_2, \dots, x_p$ s'écrit sous forme développée :

$$\begin{cases} a_{1,1}x_1 + a_{1,2}x_2 + \dots + a_{1,p}x_p = b_1 \\ a_{2,1}x_1 + a_{2,2}x_2 + \dots + a_{2,p}x_p = b_2 \\ \vdots \\ a_{n,1}x_1 + a_{n,2}x_2 + \dots + a_{n,p}x_p = b_n \end{cases}$$

Il s'exprime de manière compacte sous la forme matricielle équivalente : $$A \cdot X = B$$ où $A \in \mathcal{M}_{n, p}(\mathbb{R})$ est la matrice des coefficients, $X \in \mathcal{M}_{p, 1}(\mathbb{R})$ est le vecteur colonne des inconnues, et $B \in \mathcal{M}_{n, 1}(\mathbb{R})$ est le second membre.

2. L'Algorithme du Pivot de Gauss & Opérations Élémentaires

L'objectif de l'algorithme d'élimination de Gauss est de transformer le système en un système triangulaire supérieur équivalent au moyen des trois opérations élémentaires sur les lignes :

Échange de Lignes

L_i <-> L_j

Permute l'ordre de deux équations.

Multiplication Scalaire

L_i <- \lambda \cdot L_i \quad (\lambda \neq 0)

Multiplie une équation par une constante non nulle.

Combinaison Linéaire

L_i <- L_i - \alpha \cdot L_j

Élimine une variable sous le pivot.

3. Résolution Complète d'un Système 3x3 Pas-à-Pas (Partiel Corrigé)

Énoncé : Résoudre dans $\mathbb{R}^3$ le système $(S)$ :

$$\begin{cases} x + 2y + z = 8 & (L_1) \\ 2x + 3y + 4z = 20 & (L_2) \\ 4x + 3y + 2z = 16 & (L_3) \end{cases}$$

Déroulement rigoureux du Pivot de Gauss :

Étape 1 : Choix du premier pivot sur $L_1$ : $p_1 = 1 \neq 0$. On élimine $x$ sur $L_2$ et $L_3$ :
• $L_2 \leftarrow L_2 - 2L_1 \implies (2-2)x + (3-4)y + (4-2)z = 20 - 16 \implies \mathbf{-y + 2z = 4}$
• $L_3 \leftarrow L_3 - 4L_1 \implies (4-4)x + (3-8)y + (2-4)z = 16 - 32 \implies \mathbf{-5y - 2z = -16}$

Étape 2 : Choix du second pivot sur $L_2$ : $p_2 = -1 \neq 0$. On élimine $y$ sur $L_3$ :
• $L_3 \leftarrow L_3 - 5L_2 \implies (-5 - (-5))y + (-2 - 10)z = -16 - 20 \implies \mathbf{-12z = -36} \implies \mathbf{z = 3}$

Étape 3 : Remontée triangulaire (Substitution arrière) :
• De $L_2$ : $-y + 2(3) = 4 \implies -y = -2 \implies \mathbf{y = 2}$
• De $L_1$ : $x + 2(2) + 3 = 8 \implies x + 7 = 8 \implies \mathbf{x = 1}$

Conclusion : Le système admet une solution unique : $\mathcal{S} = \{(1, 2, 3)\}$.
