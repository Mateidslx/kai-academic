1. Le Canevas d'un Script Bash Robuste et Professionnel

À l'IUT d'Anglet, un script Shell doit respecter des conventions strictes de clarté, de gestion des erreurs et de modularité : 

#!/bin/bash
# ==============================================================================
# Nom        : surveillance_disque.sh
# Rôle       : Vérifie l'occupation disque et alerte si le seuil dépasse 90%
# Auteur     : Matéi de Saint Leger (BUT 1 Informatique Anglet)
# ==============================================================================
set -euo pipefail # Arrêt immédiat si une commande échoue ou variable non définie
IFS=$'
	'       # Délimiteur de champ sécurisé pour éviter le word splitting

SEUIL_MAX=90

# Fonction d'affichage d'aide
usage() {
    echo "Usage : $0 [seuil_en_pourcentage]" >&2
    exit 1
}

if [ "$#" -ge 1 ]; then
    SEUIL_MAX="$1"
fi

echo "[INFO] Démarrage de la surveillance avec seuil = ${SEUIL_MAX}%"

2. Les Variables Spéciales Fondamentales en Bash

Variable Contenu Sémantique Strict Exemple Typique d'Usage
$0 Nom ou chemin sous lequel le script a été invoqué. Messages d'aide echo "Usage : $0 <fichier>"
$1, $2, ... $9 Les paramètres positionnels passés au script. SOURCE="$1"
${10}, ${11} Paramètres au-delà du 9ème (accolades obligatoires !). Accès aux arguments multiples
$# Nombre exact d'arguments passés au script. if [ "$#" -ne 2 ]; then usage; fi
$? Code de retour (exit status) de la dernière commande exécutée ($0$ = succès, $ eq 0$ = erreur). Vérification post-exécution
$@ Liste de tous les arguments sous forme de mots séparés "$1" "$2" .... Boucle for arg in "$@"; do
$$ Numéro de processus (PID) du script en cours d'exécution. Fichiers temporaires uniques /tmp/temp_$$

3. Tests Conditionnels : Les Opérateurs Cruciaux

La syntaxe standard [ condition ] (équivalente à la commande test) exige des espaces obligatoires après [ et avant ] :

  • Tests sur Fichiers :
    • [ -e "$f" ] : Le fichier ou dossier existe.
    • [ -f "$f" ] : C'est un fichier ordinaire régulier.
    • [ -d "$f" ] : C'est un répertoire.
    • [ -r "$f" ], [ -w "$f" ], [ -x "$f" ] : Droit en lecture, écriture ou exécution.
    • [ -s "$f" ] : Le fichier existe et sa taille est strictement supérieure à 0 octet.
  • Comparaisons Numériques :
    -eq (égal), -ne (différent), -lt (inférieur strict), -le (inférieur ou égal), -gt (supérieur strict), -ge (supérieur ou égal).
  • Comparaisons de Chaînes :
    [ "$chaine1" = "$chaine2" ] (égalité), [ -z "$str" ] (chaîne vide de longueur nulle), [ -n "$str" ] (chaîne non vide).

4. Boucles et Fonctions Structurées

# Parcours de tous les fichiers .c du dossier courant
for fichier in *.c; do
    if [ -f "$fichier" ]; then
        echo "Compilation de $fichier..."
        gcc -Wall -Wextra -Werror -g "$fichier" -o "${fichier%.c}.bin"
    fi
done

# Déclaration d'une fonction avec variables locales
calculer_somme() {
    local a="$1"
    local b="$2"
    local resultat=$(( a + b ))
    echo "$resultat"
}

TOTAL=$(calculer_somme 15 27)
echo "Total calculé : $TOTAL"
