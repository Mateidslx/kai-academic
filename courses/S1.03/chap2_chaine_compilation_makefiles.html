1. Les 4 Étapes de la Chaîne de Compilation C/C++

Transformer un fichier source textuel main.cpp en un binaire exécutable machine est un processus décomposé en 4 étapes séquentielles :

  1. 1. Préprocesseur (cpp) :
    Traite toutes les directives commençant par #. Il remplace textuellement les #include par le contenu des fichiers d'en-tête, évalue les macros #define et filtre le code conditionnel #ifdef. Produit un fichier intermédiaire .i.
  2. 2. Compilateur (g++ -S) :
    Analyse syntaxique, sémantique et typage formel. Traduit le code C++ prétraité en instructions assembleur spécifiques à l'architecture du processeur cible (x86_64, ARM64). Produit un fichier assembleur .s.
  3. 3. Assembleur (as -c) :
    Traduit les instructions assembleur en code machine binaire sous forme de fichier objet relogeable (format ELF sous Linux, Mach-O sous macOS, PE-COFF sous Windows). Produit un fichier objet .o.
  4. 4. Éditeur de Liens (ld) :
    Résout les symboles externes (adresses des fonctions définies dans d'autres modules ou dans les bibliothèques système comme la libc++), assemble les sections de code et génère le fichier binaire exécutable final.

2. Les Drapeaux d'Excellence du Compilateur GCC/Clang

À l'IUT d'Anglet, toute compilation doit impérativement comporter les drapeaux stricts suivants : 

g++ -std=c++17 -Wall -Wextra -Werror -g -O2 src/main.cpp -o app
  • -Wall -Wextra : Active tous les avertissements standards et avancés du compilateur (variables non initialisées, conversions de types risquées, paramètres inutilisés).
  • -Werror : Transforme chaque avertissement en erreur fatale bloquante. Rien n'est toléré qui ne soit parfait !
  • -g : Génère les tables de symboles de débogage pour les outils GDB et Valgrind.
  • -O2 : Active les optimisations de performance du compilateur (inlining de fonctions, déroulage de boucles, vectorisation SIMD).

3. Anatomie d'un Makefile Professionnel Automatisé

L'utilitaire make automatise la compilation incrémentale : seuls les fichiers .cpp modifiés depuis la dernière compilation sont réassemblés, évitant de recompiler tout le projet inutilement : 

CXX := g++
CXXFLAGS := -std=c++17 -Wall -Wextra -Werror -g -Iinclude -MMD -MP
SRC_DIR := src
OBJ_DIR := obj
BIN_DIR := bin

SRCS := $(wildcard $(SRC_DIR)/*.cpp)
OBJS := $(SRCS:$(SRC_DIR)/%.cpp=$(OBJ_DIR)/%.o)
DEPS := $(OBJS:.o=.d)
TARGET := $(BIN_DIR)/application_sae

.PHONY: all clean run test

all: $(TARGET)

$(TARGET): $(OBJS) | $(BIN_DIR)
	$(CXX) $(CXXFLAGS) $^ -o $@

$(OBJ_DIR)/%.o: $(SRC_DIR)/%.cpp | $(OBJ_DIR)
	$(CXX) $(CXXFLAGS) -c $< -o $@

$(BIN_DIR) $(OBJ_DIR):
	mkdir -p $@

clean:
	rm -rf $(OBJ_DIR) $(BIN_DIR)

run: all
	./$(TARGET)

-include $(DEPS)
