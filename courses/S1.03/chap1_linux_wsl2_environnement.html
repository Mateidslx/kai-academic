Chapitre 1 : Installation & Configuration de Linux / WSL2 pour le Développement

Mise en place de la distribution Ubuntu sous WSL2, gestionnaire de paquets apt, configuration de l'éditeur de code et variables d'environnement.

1. Architecture des Systèmes d'Exploitation GNU/Linux & WSL2

L'environnement GNU/Linux constitue le standard universel pour le développement logiciel professionnel, l'hébergement cloud et l'administration système. À l'IUT d'Anglet, les étudiants exploitent Linux nativement ou via WSL2 (Windows Subsystem for Linux 2), qui exécute un véritable noyau Linux virtualisé ultra-léger au-dessus d'un hyperviseur Hyper-V de type 1.

2. La Norme FHS (Filesystem Hierarchy Standard)

Sous Linux, tout est fichier ou flux. L'arborescence racine unique / est structurée selon des conventions strictes :

Répertoire Rôle Système Exemples de Contenu
/bin, /usr/bin Binaires exécutables fondamentaux du système et des utilisateurs bash, gcc, g++, ls, cat, git
/etc Fichiers de configuration globale du système /etc/passwd, /etc/hosts, /etc/ssh/sshd_config
/home Répertoires personnels des utilisateurs non privilégiés /home/ubuntu/, fichiers personnels, ~/.bashrc
/var Données variables dynamiques (logs, bases de données) /var/log/syslog, /var/log/nginx/
/tmp Fichiers temporaires purgés au redémarrage Sockets IPC, scripts scratch temporaires

3. Gestion des Permissions Unix & Modèle Octal

Chaque fichier ou dossier dispose d'un triplet de droits pour 3 entités : le Propriétaire (User u), le Groupe (Group g), et les Autres (Others o).
Les 3 permissions de base sont pondérées en binaire/octal :

  • Lecture (r = read) : Valeur $4$. Autorise la lecture du fichier ou le listage d'un répertoire.
  • Écriture (w = write) : Valeur $2$. Autorise la modification du fichier ou la création/suppression dans un répertoire.
  • Exécution (x = execute) : Valeur $1$. Autorise l'exécution d'un binaire/script ou la traversée (cd) d'un répertoire.
# Exemple : attribuer rwxr-xr-- (754)
chmod 754 mon_script.sh

# Sécuriser une clé privée SSH (lecture et écriture exclusives par le propriétaire) :
chmod 600 ~/.ssh/id_ed25519

4. Variables d'Environnement & Redirections de Flux

Le shell gère trois descripteurs de fichiers standards pour chaque processus :

  • 0 (stdin) : Flux d'entrée standard (clavier par défaut).
  • 1 (stdout) : Flux de sortie standard (écran du terminal par défaut).
  • 2 (stderr) : Flux d'erreur standard (séparé pour isoler les messages d'anomalie).
# Redirection de stdout et stderr dans des fichiers distincts :
./mon_programme > sortie.txt 2> erreurs.log

# Redirection combinée (stdout + stderr fusionnés) :
./mon_programme > execution.log 2>&1

# Redirection par pipeline vers un filtre :
grep -rn "ERROR" /var/log/ | wc -l
