1. Le Modèle Objet du Document (DOM) & Sélection Moderne

Le navigateur parse le code HTML brut et produit un arbre d'objets en mémoire : le DOM (Document Object Model). En JavaScript moderne, on bannit les anciennes méthodes comme document.getElementById ou document.getElementsByClassName au profit des sélecteurs CSS normalisés : 

// Sélection d'un élément unique
const submitBtn = document.querySelector('#btnSubmit');

// Sélection d'une collection d'éléments (NodeList statique itérable)
const cards = document.querySelectorAll('.course-card');
cards.forEach(card => {
    card.classList.add('shadow-sm');
});

2. Événements, Phase de Capture & Bouillonnement (Bubbling)

Lors d'un clic utilisateur, l'événement traverse d'abord le DOM du sommet vers la cible (phase de capture), puis remonte de la cible vers la racine (phase de bouillonnement ou bubbling). 

// Délégation d'événements performante sur le conteneur parent
const listContainer = document.querySelector('#todoList');

listContainer.addEventListener('click', (event) => {
    // Vérifie si le clic provient d'un bouton de suppression
    if (event.target.matches('.btn-delete')) {
        const itemId = event.target.dataset.id;
        supprimerTache(itemId);
    }
});

// Prévention du comportement par défaut
const form = document.querySelector('#authForm');
form.addEventListener('submit', (event) => {
    event.preventDefault(); // Stoppe le rechargement brutal de la page
    traiterConnexion();
});

3. Programmation Asynchrone : De Callback Hell à Async/Await

JavaScript s'exécute dans un unique thread d'exécution cadencé par une boucle d'événements (Event Loop). Pour ne jamais geler l'interface graphique lors d'appels réseau, toutes les opérations I/O sont asynchrones. 

/**
 * Récupère les données d'un cours depuis l'API distante avec gestion d'erreurs
 * @param {string} courseCode - Le code de la ressource (ex: 'R1.06')
 * @returns {Promise<object>} Données du cours décodées en JSON
 */
async function fetchCourseData(courseCode) {
    const endpoint = `/api/courses/${encodeURIComponent(courseCode)}`;
    
    try {
        const response = await fetch(endpoint, {
            method: 'GET',
            headers: {
                'Accept': 'application/json',
                'X-Requested-With': 'XMLHttpRequest'
            }
        });

        // ATTENTION : fetch ne rejette pas en cas d'erreur HTTP 404 ou 500 !
        if (!response.ok) {
            throw new Error(`Erreur réseau HTTP ${response.status} (${response.statusText})`);
        }

        const data = await response.json();
        return data;
    } catch (error) {
        console.error(`[API Error] Échec de récupération pour ${courseCode}:`, error);
        afficherNotificationErreur("Impossible de charger les données du cours.");
        throw error; // Propage l'erreur pour le gestionnaire d'interface
    }
}

QUESTION 1 / 4 R1.02 • Ch.4

Que retourne l'appel à la fonction « fetch(url) » en JavaScript moderne ?

Explication Pédagogique : L'API Fetch est entièrement asynchrone basée sur les Promesses. Pour récupérer le corps JSON décodé, il faut chaîner un second appel : fetch(url).then(res => res.json()).then(data => { ... }) ou utiliser 'const res = await fetch(url); const data = await res.json();'.
QUESTION 2 / 4 R1.02 • Ch.4

En JavaScript moderne, quelle est la méthode recommandée pour écouter un événement (comme un clic de souris) sur un bouton ?

Explication Pédagogique : addEventListener est la méthode standard du W3C : elle permet d'attacher plusieurs écouteurs indépendants sur le même événement sans écraser les précédents, et offre un contrôle complet sur la phase de propagation (capture/bubbling).
QUESTION 3 / 4 R1.02 • Ch.4

Que réalise la méthode « event.preventDefault() » appelée dans un gestionnaire d'événement de soumission de formulaire ('submit') ?

Explication Pédagogique : Par défaut, soumettre un formulaire déclenche une requête HTTP synchrone qui recharge toute la page. 'event.preventDefault()' annule ce comportement par défaut, permettant une interface réactive et moderne.
