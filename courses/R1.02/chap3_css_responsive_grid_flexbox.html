R1.02 • CHAPITRE 3

CSS3 Moderne : Box Model, Flexbox 1D, CSS Grid 2D & Responsive Design

Enseignant Référent : Mme Sophie Voisin / M. Roegel — IUT de Bayonne et du Pays Basque (Campus d'Anglet)

Modèle de boîte box-sizing border-box, mise en page unidimensionnelle Flexbox, grille bidimensionnelle Grid, variables CSS et media queries adaptatives.

1. Le Modèle de Boîte & box-sizing: border-box

Par défaut en CSS standard (content-box), la largeur d'un élément (width) ne prend en compte que le contenu. L'ajout d'un padding de 20px et d'une bordure de 2px élargit l'élément au-delà de sa dimension déclarée, brisant les grilles de mise en page.

La règle universelle et indispensable à tout projet moderne consiste à forcer le calcul global : 

*, *::before, *::after {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

2. Flexbox : Le Maître de la Mise en Page Unidimensionnelle (1D)

Flexbox organise les éléments le long d'un axe unique : Main Axis (horizontal par défaut) et Cross Axis (vertical par défaut). 

.navbar {
    display: flex;
    flex-direction: row;            /* Axe principal horizontal */
    justify-content: space-between; /* Répartition des enfants le long du main axis */
    align-items: center;            /* Centrage le long du cross axis */
    gap: 1.5rem;                    /* Espacement propre entre enfants sans margin hack */
    padding: 1rem 2rem;
}

.nav-link {
    flex-grow: 0;                   /* Ne s'étire pas au-delà de sa taille naturelle */
    flex-shrink: 0;                 /* Ne s'écrase pas en cas d'espace réduit */
}

.search-input {
    flex-grow: 1;                   /* Occupe tout l'espace restant disponible */
}

3. CSS Grid : La Puissance de la Mise en Page Bidimensionnelle (2D)

CSS Grid permet de concevoir des architectures complètes à la fois en lignes (rows) et en colonnes (columns). 

/* Dashboard universitaire adaptatif sans aucune media query ! */
.course-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(320px, 1fr));
    gap: 1.5rem;
    padding: 2rem;
}

/* Mise en page structurelle avec grid-template-areas */
.app-layout {
    display: grid;
    grid-template-areas:
        "header  header"
        "sidebar main"
        "footer  footer";
    grid-template-columns: 280px 1fr;
    grid-template-rows: auto 1fr auto;
    min-height: 100vh;
}

.app-header  { grid-area: header; }
.app-sidebar { grid-area: sidebar; }
.app-main    { grid-area: main; }
.app-footer  { grid-area: footer; }

4. Media Queries & Philosophie Mobile-First

Dans l'approche Mobile-First, on commence par styliser pour les petits écrans tactiles, puis on enrichit progressivement l'interface au fur et à mesure que l'écran s'élargit grâce à min-width : 

/* Styles mobiles par défaut (base) */
.sidebar {
    display: none; /* Menu replié en tiroir */
}

/* Tablette et Desktop (écran >= 768px) */
@media (min-width: 768px) {
    .sidebar {
        display: block;
        width: 260px;
    }
    .main-content {
        padding: 2rem;
    }
}

/* Grand écran (>= 1200px) */
@media (min-width: 1200px) {
    .container {
        max-width: 1140px;
        margin: 0 auto;
    }
}
