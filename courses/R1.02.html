R1.02 — Développement d'Interfaces Web

Enseignant Référent : Mme Sophie Voisin / M. Roegel — IUT de Bayonne et du Pays Basque (Campus d'Anglet)

Architecture client-serveur approfondie, protocole HTTP (HTTP/1.1, HTTP/2, HTTP/3 QUIC, en-têtes, statuts, méthodes), intégration HTML5 sémantique et accessibilité universelle W3C WCAG AAA, mise en page CSS3 avancée (Flexbox 1D, CSS Grid 2D, Responsive Design), programmation JavaScript moderne ES6+ (DOM, Événements, Fetch asynchrone), et sécurité défensive des applications Web (XSS, CSRF, CSP, CORS).
