Partitions d'Ensembles & Simplifications Algébriques

Enseignant Référent : Mme Marie Bruyère / Mme Roegel — IUT de Bayonne et du Pays Basque (Campus d'Anglet)

Définition axiomatique d'une partition, lois de l'algèbre de Boole des ensembles, lois de De Morgan et méthode pas-à-pas de simplification d'expressions.

1. Définition Axiomatique d'une Partition

Soit $E$ un ensemble non vide. Une famille de sous-ensembles $\{A_1, A_2, \dots, A_k\}$ de $E$ constitue une partition de $E$ si et seulement si les trois axiomes stricts suivants sont simultanément vérifiés :

  1. Non-vacuité : Aucun sous-ensemble de la partition n'est vide : $$\forall i \in \{1, \dots, k\}, \quad A_i \neq \emptyset$$
  2. Disjonction deux à deux : Deux sous-ensembles distincts quelconques n'ont aucun élément commun : $$\forall i \neq j, \quad A_i \cap A_j = \emptyset$$
  3. Recouvrement total : La réunion de tous les sous-ensembles reconstitue exactement l'ensemble $E$ : $$\bigcup_{i=1}^k A_i = A_1 \cup A_2 \cup \dots \cup A_k = E$$
Exemples types d'examens (IUT d'Anglet) :
  • Dans $\mathbb{Z}$ : L'ensemble des entiers pairs $2\mathbb{Z}$ et l'ensemble des entiers impairs $2\mathbb{Z}+1$ forment une partition de $\mathbb{Z}$.
  • Dans un jeu de 32 cartes : La famille $\{\text{Cœur}, \text{Carreau}, \text{Pique}, \text{Trèfle}\}$ est une partition du jeu.
  • Contre-exemple classique : $\{\{1, 2\}, \{2, 3\}\}$ sur $\{1, 2, 3\}$ n'est PAS une partition car $\{1, 2\} \cap \{2, 3\} = \{2\} \neq \emptyset$ (échec de la disjonction).

2. Lois Fondamentales de l'Algèbre des Ensembles

Les opérations $\cup$ et $\cap$ avec le complémentaire vérifient les propriétés suivantes dans l'univers $E$ :

Propriété Pour l'Union ($\cup$) Pour l'Intersection ($\cap$)
Commutativité $A \cup B = B \cup A$ $A \cap B = B \cap A$
Associativité $(A \cup B) \cup C = A \cup (B \cup C)$ $(A \cap B) \cap C = A \cap (B \cap C)$
Distributivité $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$
Idempotence $A \cup A = A$ $A \cap A = A$
Éléments Neutres $A \cup \emptyset = A$ $A \cap E = A$
Éléments Absorbants $A \cup E = E$ $A \cap \emptyset = \emptyset$
Complémentarité $A \cup \overline{A} = E$ $A \cap \overline{A} = \emptyset$
Involution $\overline{\overline{A}} = A$

3. Les Lois de De Morgan

Les lois de De Morgan permettent de distribuer la négation (complémentaire) en inversant les connecteurs ensemblistes :

$$\overline{A \cup B} = \overline{A} \cap \overline{B}$$ $$\overline{A \cap B} = \overline{A} \cup \overline{B}$$

4. Exercice Guidé : Simplification d'Expression Ensembliste

Énoncé d'examen : Simplifier l'expression $X = (A \cap B) \cup (A \cap \overline{B}) \cup (\overline{A} \cap B)$.

Étape 1 : Factorisation par distributivité sur les deux premiers termes :

$$(A \cap B) \cup (A \cap \overline{B}) = A \cap (B \cup \overline{B})$$

Étape 2 : Or par complémentarité, $B \cup \overline{B} = E$. Donc :

$$A \cap (B \cup \overline{B}) = A \cap E = A$$

Étape 3 : Réinjection dans l'expression globale :

$$X = A \cup (\overline{A} \cap B)$$

Étape 4 : Distributivité de $\cup$ par rapport à $\cap$ :

$$X = (A \cup \overline{A}) \cap (A \cup B) = E \cap (A \cup B) = A \cup B$$

Conclusion : $X = A \cup B$.

QUESTION 1 / 4 R1.06 • Ch.2

Que signifie la « distributivité » du connecteur ET (∧) sur le connecteur OU (∨) en logique ?

Explication Pédagogique : Comme la multiplication se distribue sur l'addition en algèbre numérique a * (b + c) = a*b + a*c, le connecteur ET se distribue sur le OU. Remarquablement, en algèbre de Boole, le OU se distribue aussi sur le ET : P ∨ (Q ∧ R) ⇔ (P ∨ Q) ∧ (P ∨ R).
QUESTION 2 / 4 R1.06 • Ch.2

Quelles sont les Lois de De Morgan appliquées à la complémentation d'ensembles ?

Explication Pédagogique : Le complémentaire d'une union est l'intersection des complémentaires ; le complémentaire d'une intersection est l'union des complémentaires. Cette dualité se retrouve à l'identique en logique booléenne.
QUESTION 3 / 4 R1.06 • Ch.2

Qu'est-ce qu'une « partition » d'un ensemble E non vide ?

Explication Pédagogique : Définition rigoureuse de Mme Fernandes : une partition découpe E en blocs sans aucun chevauchement et sans rien oublier : 1. Aucun bloc n'est vide, 2. Si A ≠ B, alors A ∩ B = ∅, 3. L'union de tous les blocs est égale à E.
QUESTION 4 / 4 R1.06 • Ch.2

Quel théorème fondamental lie les relations d'équivalence et les partitions d'un ensemble ?

Explication Pédagogique : Théorème central du cours de Mme Fernandes : la classe d'équivalence de x, notée cl(x), regroupe tous les éléments y tels que x R y. Deux classes sont soit strictement disjointes, soit totalement confondues. L'ensemble quotient E/R est une partition de E.
