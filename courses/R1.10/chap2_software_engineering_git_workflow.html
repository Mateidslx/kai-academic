1. Modern Version Control & Git Terminology

Git Command / Concept French Concept Professional Engineering Explanation
Repository (Repo) Dépôt de code The central directory containing project files and their complete version history tracked by Git.
Commit Instantané / Validation An immutable snapshot of the staging area recorded into the project's permanent Git ledger with an SHA-1/SHA-256 hash and descriptive message.
Branch Branche de développement An independent line of development branching off the main codebase (e.g., feature/login-jwt).
Merge Conflict Conflit de fusion Occurs when two competing branches modify the exact same lines of code in incompatible ways, requiring manual developer resolution.
Pull Request (PR) Demande de relecture / intégration A proposed change submitted to a repository where peers review the code diff, run automated CI checks, and approve before merging.

2. Software Quality & Testing Vocabulary

  • Code Smells : Syntactic or architectural patterns in source code that indicate deeper design problems (e.g., God objects, duplicate code).
  • Refactoring : The process of restructuring existing computer code without changing its external behavior to improve non-functional attributes (readability, maintainability).
  • Unit Testing : Automated tests verifying individual isolated functions or methods for correctness.
  • Mock Object : A simulated object that mimics the behavior of real, complex dependencies (such as external databases or payment APIs) during testing.
  • Code Coverage : Metric measuring the percentage of source code executed while the test suite runs (target $\ge 80\%$).
  • Memory Leak : A resource leak occurring when a program fails to release dynamically allocated memory (using free or delete) that is no longer needed.
