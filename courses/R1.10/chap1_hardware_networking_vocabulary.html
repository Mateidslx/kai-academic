Chapitre 1 : Hardware, Networking & System Architecture Vocabulary

Core computer components (motherboard, CPU, GPU, storage), networking protocols (TCP/IP, routing, DNS, bandwidth), cloud services and server terminology.

1. Hardware & System Architecture Glossary

English Term French Translation Rigorous Technical Definition & Context
Motherboard Carte mère The main printed circuit board (PCB) that connects the CPU, memory, storage, and peripheral expansion slots.
Bus Bus de communication A shared set of physical electrical lines carrying data, addresses, or control signals between computer components.
Throughput Débit effectif / utile The actual rate at which data is successfully transferred over a network or processed by a system in a given timeframe (measured in bps or ops/s).
Bandwidth Bande passante The theoretical maximum data transfer capacity of a communication channel or network link.
Bottleneck Goulot d'étranglement A component or subsystem whose limited performance restricts the overall capacity and speed of the entire system.
Clock Rate Fréquence d'horloge The frequency at which the processor's internal clock ticks (measured in GHz), synchronizing instruction execution.
Solid-State Drive (SSD) Disque SSD (mémoire flash) A high-speed non-volatile storage device using NAND flash memory cells, featuring zero mechanical moving parts.
Latency Latence / Délai d'attente The time delay between the initiation of a request and the beginning of the corresponding response.

2. Networking & Operating Systems Vocabulary

  • Subnet Mask (Masque de sous-réseau) : A 32-bit number dividing an IP address into network and host portions.
  • Default Gateway (Passerelle par défaut) : The routing node used by a host to send packets outside its local subnet.
  • Thread (Fil d'exécution) : The smallest unit of execution within a process that can be scheduled by the OS kernel.
  • Context Switch (Changement de contexte) : The process of storing the state of a running process or thread so that execution can be resumed later, while loading another one.
  • Deadlock (Interblocage) : A state where two or more processes are permanently blocked because each is waiting for a resource held by another.

3. Critical False Friends in Computer Science

🚨 NEVER MAKE THESE MISTAKES IN EXAMS OR TECHNICAL INTERVIEWS :

  • Actually means « en réalité » or « en fait » (NOT « actuellement », which is currently or at present).
  • Eventually means « finalement / à terme » (NOT « éventuellement », which is possibly).
  • Library means « bibliothèque logicielle » (NOT « librairie commerciale », which is bookstore / bookshop).
  • Effective means « efficace / qui produit l'effet attendu » (NOT « effectif », which is actual / real).
  • Resume means « reprendre une tâche interrompue » (NOT « résumer », which is to summarize).
