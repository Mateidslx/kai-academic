Modèle 5 — La recherche de première occurrence

Coeff Grille : 10/30 (Codage) + 4/30 (Justif)
Arbre d'Actions Formel (Décomposition & SFD selon M. Etcheverry) :
Algorithme Papier (Pseudo-code) :
i <- 0
trouve <- Faux

TantQue (i < TAILLE) ET (NON trouve) Faire
    Si tab[i] = cible Alors
        trouve <- Vrai
    Sinon
        i <- i + 1
    FinSi
FinTantQue

Si trouve Alors
    Afficher "Cible trouvée à l'indice ", i
Sinon
    Afficher "Cible absente du tableau."
FinSi
Justification Officielle à l'Oral (/30) :

« Le parcours est partiel et s'arrête dès que la cible ou la première anomalie est rencontrée grâce à un booléen et une boucle while. »

Code C++ Conforme AST Prof (Tripartition & Allman) :
i = 0;
trouve = false;

while ((i < TAILLE) && !trouve)
{
    if (tab[i] == cible)
    {
        trouve = true;
    }
    else
    {
        i++; // Incrémentation UNIQUEMENT dans le else pour préserver l'indice trouvé !
    }
}

if (trouve)
{
    cout << "Trouve a l'indice : " << i << endl;
}
else
{
    cout << "Non trouve." << endl;
}
