Modèle 5 — La recherche de première occurrence

Coeff Grille : 10/30 (Codage) + 4/30 (Justif)
Schéma Formel d'Exécution :
Justification Officielle :

« Le parcours est partiel et s'arrête dès que la cible ou la première anomalie est rencontrée grâce à un booléen et une boucle while. »

Algorithme Papier (Pseudo-code) :
i <- 0
trouve <- Faux

TantQue (i < TAILLE) ET (NON trouve) Faire
    Si tab[i] = cible Alors
        trouve <- Vrai
    Sinon
        i <- i + 1
    FinSi
FinTantQue

Si trouve Alors
    Afficher "Cible trouvée à l'indice ", i
Sinon
    Afficher "Cible absente du tableau."
FinSi
Code C++ Conforme AST Prof (Tripartition & Allman) :
i = 0;
trouve = false;

while ((i < TAILLE) && !trouve)
{
    if (tab[i] == cible)
    {
        trouve = true;
    }
    else
    {
        i++; // Incrémentation UNIQUEMENT dans le else pour préserver l'indice trouvé !
    }
}

if (trouve)
{
    cout << "Trouve a l'indice : " << i << endl;
}
else
{
    cout << "Non trouve." << endl;
}

Exemple 2C (Prédiction 2026) — Saisie de deux cotes et tri croissant de 2 valeurs

Modèle 2 (Saisie-vérification) + Modèle 1 (Échange de deux valeurs)

Énoncé Type : Saisir deux réels (largeur et longueur) strictement positifs avec contrôle de saisie, puis permuter leurs valeurs si largeur > longueur afin de garantir l'ordre croissant.

Justification Prof : « Deux boucles for(;;) avec break pour valider les deux cotes > 0, puis un test if(largeur > longueur) avec variable temporaire copie pour échanger sans perte. »

Algorithme Papier (Pseudo-code) :

Répéter

FinRépéter

// 2. Saisie-vérification longueur

        SortirDeBoucle
    FinSi
    Afficher "Erreur : la longueur doit être strictement positive !"
FinRépéter

Si largeur > longueur Alors

#include <iostream>
using namespace std;

int main()
{
    float largeur;  // Cote minimale
    float longueur; // Cote maximale
    float copie;    // Tampon d'échange

    // 1. INITIALISER ET SAISIR-VÉRIFIER LARGEUR
    for (;;)
    {
        cout << "Entrez la largeur (> 0) : ";
        cin >> largeur;
        if (largeur > 0.0f)
        {
            break;
        }
        cout << "Erreur : largeur invalide !" << endl;
    }

    // SAISIR-VÉRIFIER LONGUEUR
    for (;;)
    {
        cout << "Entrez la longueur (> 0) : ";

        {
            break;
        }
        cout << "Erreur : longueur invalide !" << endl;

    // 2. TRAITER : ÉCHANGE CONDITIONNÉ
    if (largeur > longueur)
    {
        copie = largeur;
        largeur = longueur;
