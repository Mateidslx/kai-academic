KATA 2 OFFICIEL (OSINT) • EXERCICE 1 / 9 • CEINTURE BLANCHE Modèle : La saisie-vérification d'une valeur

Kata 2 Officiel — Ex. 1 : Saisie-vérification d'une température en °C dans [-30 ; 50]

🎯 Énoncé & But de l'exercice :
Saisir et vérifier une température en degrés Celsius comprise entre -30 et 50 inclus avec message d'erreur explicite, puis afficher la température validée.
🧠 Justification officielle du modèle :
Énoncé réel du Kata 2 (Ex. 1) : l'utilisateur doit saisir une température valide dans [-30 ; 50]. Le nombre de tentatives est inconnu a priori avec affichage d'un message d'erreur avant rebouclage : on utilise le modèle de saisie-vérification avec boucle infinie for ( ; ; ) et sortie break.
/**
 * Numéro du groupe : 16 (TP4)
 * Nom du groupe : Les Flèches de la Précision
 * Étudiants : Matei De Saint Leger, Nicolas Gence, Jules Tison
 * Numéro de Kata : Kata 2
 * Numéro de l'exercice : 1 (Ceinture Blanche)
 * But de l'exercice : Saisir et vérifier une température en degrés Celsius comprise entre -30 et 50.
 * Modèle(s) d'algorithme(s) choisi(s) : La saisie-vérification d'une valeur
 * Brève justification du ou des modèles choisis : Il faut répéter la saisie tant que la température n'est pas comprise dans l'intervalle [-30 ; 50] en affichant un message d'erreur en cas de valeur hors bornes.
 * Remarques éventuelles : Conforme à l'arbre méthodologique R1.01 (for(;;) + break) et sans nombre magique.
 */
#include <iostream>
using namespace std;

int main()
{
    // CONSTANTES
    const short int TEMP_MIN = -30; // Température minimale autorisée en degrés Celsius
    const short int TEMP_MAX = 50;  // Température maximale autorisée en degrés Celsius

    // VARIABLES
    short int temperature; // Température en degrés Celsius saisie par l'utilisateur

    // TRAITEMENTS
    // Saisir et vérifier la température dans [TEMP_MIN ; TEMP_MAX] >> temperature
    for ( ; ; )
    {
        cout << "Saisissez une temperature entre " << TEMP_MIN << " et " << TEMP_MAX << " : ";
        cin >> temperature;

        if ((temperature >= TEMP_MIN) && (temperature <= TEMP_MAX))
        {
            break;
        }

        cout << "Valeur incorrecte, veuillez saisir une temperature entre "
             << TEMP_MIN << " et " << TEMP_MAX << "." << endl;
    }

    // temperature >> Afficher la température validée >> (écran)
    cout << "Temperature valide : " << temperature << " °C" << endl;

    return 0;
}
KATA 2 OFFICIEL (OSINT) • EXERCICE 2 / 9 • CEINTURE JAUNE Modèle : La saisie-vérification d'une valeur + L'échange de deux valeurs

Kata 2 Officiel — Ex. 2 : Saisie-vérification de 2 indices et échange de caractères dans « le compilateur est ta boussole »

🎯 Énoncé & But de l'exercice :
Saisir et vérifier deux indices compris entre 0 et 29 dans la chaîne "le compilateur est ta boussole", échanger les deux caractères situés à ces indices, puis afficher la chaîne modifiée.
🧠 Justification officielle du modèle :
Énoncé réel du Kata 2 (Ex. 2) : il faut d'abord contrôler que les deux indices saisis ne dépassent pas la borne maximale de la chaîne (Modèle : Saisie-vérification), puis permuter les deux caractères correspondants sans perte d'information (Modèle : Échange de deux valeurs).
/**
 * Numéro du groupe : 16 (TP4)
 * Nom du groupe : Les Flèches de la Précision
 * Étudiants : Matei De Saint Leger, Nicolas Gence, Jules Tison
 * Numéro de Kata : Kata 2
 * Numéro de l'exercice : 2 (Ceinture Jaune)
 * But de l'exercice : Saisir deux indices valides et échanger les deux caractères correspondants dans la phrase "le compilateur est ta boussole".
 * Modèle(s) d'algorithme(s) choisi(s) : La saisie-vérification d'une valeur, L'échange de deux valeurs
 * Brève justification du ou des modèles choisis : La saisie-vérification garantit que ind1 et ind2 sont des indices valides de la chaîne, puis le modèle d'échange de deux valeurs permute phrase[ind1] et phrase[ind2] via une variable temporaire copieCaractere.
 * Remarques éventuelles : Indices non signés bornés par IND_MAX.
 */
#include <iostream>
#include <string>
using namespace std;

int main()
{
    // CONSTANTES
    const unsigned short int IND_MAX = 29; // Indice maximal valide dans la chaîne (longueur 30 : indices 0 à 29)

    // VARIABLES
    string phrase = "le compilateur est ta boussole"; // Phrase initiale à modifier
    unsigned short int ind1; // Premier indice de caractère saisi par l'utilisateur
    unsigned short int ind2; // Second indice de caractère saisi par l'utilisateur
    char copieCaractere;     // Variable temporaire pour l'échange de phrase[ind1] et phrase[ind2]

    // TRAITEMENTS
    // 1. Saisir et vérifier les deux indices ind1 et ind2 >> ind1, ind2
    for ( ; ; )
    {
        cout << "Saisissez le premier indice (entre 0 et " << IND_MAX << ") : ";
        cin >> ind1;
        cout << "Saisissez le second indice (entre 0 et " << IND_MAX << ") : ";
        cin >> ind2;

        if ((ind1 <= IND_MAX) && (ind2 <= IND_MAX))
        {
            break;
        }

        cout << "Valeur incorrecte, veuillez saisir deux indices inferieurs ou egaux a " << IND_MAX << "." << endl;
    }

    // 2. phrase, ind1, ind2 >> Échanger les caractères en ind1 et ind2 >> phrase
    copieCaractere = phrase[ind1];
    phrase[ind1] = phrase[ind2];
    phrase[ind2] = copieCaractere;

    // 3. phrase >> Afficher la phrase modifiée >> (écran)
    cout << "Nouvelle chaine : " << phrase << endl;

    return 0;
}
KATA 2 OFFICIEL (OSINT) • EXERCICE 3 / 9 • CEINTURE JAUNE-ORANGE Modèle : Le parcours complet avec traitement systématique

Kata 2 Officiel — Ex. 3 : Affichage d'un tableau d'entiers {5, 10, 15, 20, 25, 30} en partant de la fin

🎯 Énoncé & But de l'exercice :
Afficher tous les éléments du tableau {5, 10, 15, 20, 25, 30} en commençant par la dernière case (indice TAILLE_TAB - 1) jusqu'à la première case (indice 0).
🧠 Justification officielle du modèle :
Énoncé réel du Kata 2 (Ex. 3) : toutes les cases du tableau doivent être affichées sans exception, de la dernière à la première. C'est un parcours complet avec traitement systématique effectué dans le sens décroissant des indices.
/**
 * Numéro du groupe : 16 (TP4)
 * Nom du groupe : Les Flèches de la Précision
 * Étudiants : Matei De Saint Leger, Nicolas Gence, Jules Tison
 * Numéro de Kata : Kata 2
 * Numéro de l'exercice : 3 (Ceinture Jaune-Orange)
 * But de l'exercice : Afficher un tableau de 6 entiers en commençant par la fin.
 * Modèle(s) d'algorithme(s) choisi(s) : Le parcours complet avec traitement systématique
 * Brève justification du ou des modèles choisis : Chaque case du tableau doit être affichée systématiquement en parcourant les indices de TAILLE_TAB - 1 jusqu'à 0 inclus.
 * Remarques éventuelles : L'indice i est typé en short int (signé) car la condition d'arrêt i >= 0 décrémente i jusqu'à -1 en fin de boucle.
 */
#include <iostream>
using namespace std;

int main()
{
    // CONSTANTES
    const unsigned short int TAILLE_TAB = 6; // Nombre d'éléments du tableau d'entiers

    // VARIABLES
    int tabEntiers[TAILLE_TAB] = {5, 10, 15, 20, 25, 30}; // Tableau d'entiers à afficher à l'envers
    short int i; // Indice de parcours décroissant du tableau (signé pour permettre le test i >= 0)

    // TRAITEMENTS
    // tabEntiers, TAILLE_TAB >> Afficher chaque case de la dernière à la première >> (écran)
    for (i = static_cast<short int>(TAILLE_TAB) - 1; i >= 0; i--)
    {
        cout << tabEntiers[i] << endl;
    }

    return 0;
}

Kata 2 Officiel — Ex. 4 : Affichage des valeurs strictement positives du tableau {12, -5, 0, 15, -3, 20}

🎯 Énoncé & But de l'exercice :
Parcourir le tableau d'entiers {12, -5, 0, 15, -3, 20} et afficher uniquement les valeurs strictement positives (> 0).
🧠 Justification officielle du modèle :
Énoncé réel du Kata 2 (Ex. 4) : il faut inspecter toutes les cases du tableau car plusieurs valeurs peuvent être strictement positives, mais l'affichage est conditionné par le test (tabEntiers[i] > 0). Il s'agit donc du parcours complet avec traitement conditionné.
/**
 * Numéro du groupe : 16 (TP4)
 * Nom du groupe : Les Flèches de la Précision
 * Étudiants : Matei De Saint Leger, Nicolas Gence, Jules Tison
 * Numéro de Kata : Kata 2
 * Numéro de l'exercice : 4 (Ceinture Orange)
 * But de l'exercice : Afficher uniquement les valeurs strictement positives d'un tableau d'entiers.
 * Modèle(s) d'algorithme(s) choisi(s) : Le parcours complet avec traitement conditionné
 * Brève justification du ou des modèles choisis : Toutes les cases du tableau doivent être examinées de 0 à TAILLE_TAB - 1, mais seules celles vérifiant tabEntiers[i] > 0 sont affichées.
 * Remarques éventuelles : Typage précis unsigned short int pour la taille et l'indice de parcours croissant.
 */
#include <iostream>
using namespace std;

int main()
{
    // CONSTANTES
    const unsigned short int TAILLE_TAB = 6; // Nombre de cases du tableau d'entiers

    // VARIABLES
    int tabEntiers[TAILLE_TAB] = {12, -5, 0, 15, -3, 20}; // Tableau d'entiers contenant des valeurs positives, nulles et négatives
    unsigned short int i; // Indice de parcours du tableau tabEntiers

    // TRAITEMENTS
    // tabEntiers, TAILLE_TAB >> Afficher uniquement les valeurs strictement positives >> (écran)
    for (i = 0; i <= TAILLE_TAB - 1; i++)
    {
        if (tabEntiers[i] > 0)
        {
            cout << tabEntiers[i] << endl;
        }
    }

    return 0;
}
KATA 2 OFFICIEL (OSINT) • EXERCICE 5 / 9 • CEINTURE ORANGE-VERTE Modèle : Le parcours complet avec traitement conditionné (borné aux 9 premiers caractères)

Kata 2 Officiel — Ex. 5 : Recherche et remplacement d'un caractère dans les 9 premiers caractères de « Trop de boucles, tue la boucle »

🎯 Énoncé & But de l'exercice :
Dans la phrase "Trop de boucles, tue la boucle", saisir un caractère à modifier et un caractère de remplacement, remplacer toutes les occurrences dans les 9 premiers caractères uniquement, puis afficher la phrase modifiée ou un message si aucune occurrence n'a été trouvée.
🧠 Justification officielle du modèle :
Énoncé réel du Kata 2 (Ex. 5) : un caractère pouvant apparaître plusieurs fois dans les 9 premières positions (indices 0 à LIMITE - 1), il faut parcourir intégralement cette sous-partie et remplacer conditionnellement chaque occurrence tout en mémorisant si au moins un remplacement a eu lieu.
/**
 * Numéro du groupe : 16 (TP4)
 * Nom du groupe : Les Flèches de la Précision
 * Étudiants : Matei De Saint Leger, Nicolas Gence, Jules Tison
 * Numéro de Kata : Kata 2
 * Numéro de l'exercice : 5 (Ceinture Orange-Verte)
 * But de l'exercice : Rechercher et remplacer un caractère uniquement dans les 9 premiers caractères d'une phrase.
 * Modèle(s) d'algorithme(s) choisi(s) : Le parcours complet avec traitement conditionné
 * Brève justification du ou des modèles choisis : Plusieurs occurrences pouvant exister parmi les 9 premiers caractères, on parcourt toutes les positions de 0 à LIMITE - 1 en remplaçant conditionnellement les caractères égaux à charAModifier.
 * Remarques éventuelles : Un booléen remplacementEffectue permet de distinguer l'affichage final.
 */
#include <iostream>
#include <string>
using namespace std;

int main()
{
    // CONSTANTES
    const unsigned short int LIMITE = 9; // Nombre de premiers caractères de la phrase à inspecter

    // VARIABLES
    string phrase = "Trop de boucles, tue la boucle"; // Phrase soumise au remplacement partiel
    char charAModifier;         // Caractère recherché à remplacer
    char charRemplacant;        // Nouveau caractère de remplacement
    bool remplacementEffectue;  // Indique si au moins une occurrence a été trouvée et remplacée
    unsigned short int i;       // Indice de parcours des LIMITE premiers caractères

    // TRAITEMENTS
    // 1. Saisir le caractère à modifier et le caractère de remplacement >> charAModifier, charRemplacant
    cout << "Saisissez le caractere a modifier : ";
    cin >> charAModifier;
    cout << "Saisissez le caractere de remplacement : ";
    cin >> charRemplacant;

    // 2. phrase, LIMITE, charAModifier, charRemplacant >> Remplacer dans les 9 premiers caractères >> phrase, remplacementEffectue
    remplacementEffectue = false;
    for (i = 0; i <= LIMITE - 1; i++)
    {
        if (phrase[i] == charAModifier)
        {
            phrase[i] = charRemplacant;
            remplacementEffectue = true;
        }
    }

    // 3. remplacementEffectue, phrase >> Afficher le résultat >> (écran)
    if (remplacementEffectue)
    {
        cout << "Phrase modifiee : " << phrase << endl;
    }
    else
    {
        cout << "Aucune occurrence trouvee dans les " << LIMITE << " premiers caracteres." << endl;
    }

    return 0;
}
KATA 2 OFFICIEL (OSINT) • EXERCICE 6 / 9 • CEINTURE VERTE Modèle : La recherche de première occurrence

Kata 2 Officiel — Ex. 6 : Déterminer si le tableau {20, 21, 22, 23, 24, 25, 26} contient la valeur 20

🎯 Énoncé & But de l'exercice :
Déterminer et afficher si le tableau d'entiers {20, 21, 22, 23, 24, 25, 26} contient au moins une fois la valeur 20.
🧠 Justification officielle du modèle :
Énoncé réel du Kata 2 (Ex. 6) : dès que la valeur 20 est rencontrée une première fois dans le tableau, il est inutile de poursuivre le parcours. C'est l'application directe du modèle de recherche de première occurrence.
/**
 * Numéro du groupe : 16 (TP4)
 * Nom du groupe : Les Flèches de la Précision
 * Étudiants : Matei De Saint Leger, Nicolas Gence, Jules Tison
 * Numéro de Kata : Kata 2
 * Numéro de l'exercice : 6 (Ceinture Verte)
 * But de l'exercice : Déterminer et afficher si le tableau contient au moins une fois la valeur 20.
 * Modèle(s) d'algorithme(s) choisi(s) : La recherche de première occurrence
 * Brève justification du ou des modèles choisis : Il suffit de trouver une seule occurrence de la valeur 20 pour conclure positivement et arrêter immédiatement le parcours.
 * Remarques éventuelles : Structure conforme au diaporama 07-modeles-algos-basiques de M. Etcheverry.
 */
#include <iostream>
using namespace std;

int main()
{
    // CONSTANTES
    const unsigned short int TAILLE_TAB = 7; // Nombre d'éléments du tableau
    const int VAL_RECHERCHEE = 20;           // Valeur entière recherchée dans le tableau

    // VARIABLES
    int tabEntiers[TAILLE_TAB] = {20, 21, 22, 23, 24, 25, 26}; // Tableau d'entiers inspecté
    unsigned short int posCourante; // Indice courant d'inspection dans tabEntiers
    bool trouve;                    // Indique si VAL_RECHERCHEE a été trouvée

    // TRAITEMENTS
    // 1. Initialiser la recherche au premier élément >> trouve, posCourante
    trouve = false;
    posCourante = 0;

    // 2. tabEntiers, TAILLE_TAB, VAL_RECHERCHEE >> Rechercher la 1re occurrence >> trouve, posCourante
    while ((!trouve) && (posCourante < TAILLE_TAB))
    {
        if (tabEntiers[posCourante] == VAL_RECHERCHEE)
        {
            trouve = true;
        }
        else
        {
            posCourante = posCourante + 1;
        }
    }

    // 3. trouve, posCourante >> Afficher le résultat de la recherche >> (écran)
    if (trouve)
    {
        cout << "Le tableau contient la valeur " << VAL_RECHERCHEE
             << " (premiere occurrence a l'indice " << posCourante << ")." << endl;
    }
    else
    {
        cout << "Le tableau ne contient pas la valeur " << VAL_RECHERCHEE << "." << endl;
    }

    return 0;
}
KATA 2 OFFICIEL (OSINT) • EXERCICE 7 / 9 • CEINTURE BLEUE Modèle : La recherche de première occurrence (adaptée en sens décroissant depuis la fin du tableau)

Kata 2 Officiel — Ex. 7 : Recherche de l'indice de la dernière occurrence d'une valeur dans {20, 15, 10, 0, 15, 5}

🎯 Énoncé & But de l'exercice :
Saisir une valeur entière et afficher l'indice de sa dernière occurrence dans le tableau {20, 15, 10, 0, 15, 5} (ou indiquer qu'elle n'apparaît pas).
🧠 Justification officielle du modèle :
Énoncé réel du Kata 2 (Ex. 7) : chercher la dernière occurrence en partant du début obligerait à parcourir tout le tableau. En adaptant le modèle de recherche de première occurrence à rebours (de TAILLE_TAB - 1 vers 0), la première occurrence rencontrée est immédiatement la dernière occurrence du tableau !
/**
 * Numéro du groupe : 16 (TP4)
 * Nom du groupe : Les Flèches de la Précision
 * Étudiants : Matei De Saint Leger, Nicolas Gence, Jules Tison
 * Numéro de Kata : Kata 2
 * Numéro de l'exercice : 7 (Ceinture Bleue)
 * But de l'exercice : Saisir une valeur et afficher l'indice de sa dernière occurrence dans un tableau d'entiers.
 * Modèle(s) d'algorithme(s) choisi(s) : La recherche de première occurrence (en partant de la fin)
 * Brève justification du ou des modèles choisis : En démarrant la recherche par la dernière case (TAILLE_TAB - 1) et en reculant vers 0, on s'arrête dès que la cible est trouvée.
 * Remarques éventuelles : posCourante est typé en short int (signé) pour que la condition posCourante >= 0 s'arrête proprement à -1 lorsque la valeur est absente (évite le piège du wrap-around unsigned !).
 */
#include <iostream>
using namespace std;

int main()
{
    // CONSTANTES
    const unsigned short int TAILLE_TAB = 6; // Nombre d'éléments du tableau

    // VARIABLES
    int tabEntiers[TAILLE_TAB] = {20, 15, 10, 0, 15, 5}; // Tableau d'entiers dans lequel effectuer la recherche
    int valRecherchee;      // Valeur recherchée saisie par l'utilisateur
    short int posCourante;  // Indice courant partant de la fin (signé pour tester posCourante >= 0)
    bool trouve;            // Indique si valRecherchee a été localisée

    // TRAITEMENTS
    // 1. Saisir la valeur recherchée >> valRecherchee
    cout << "Quelle valeur recherchez-vous ? ";
    cin >> valRecherchee;

    // 2. Initialiser la recherche sur la dernière case du tableau >> trouve, posCourante
    trouve = false;
    posCourante = static_cast<short int>(TAILLE_TAB) - 1;

    // 3. tabEntiers, valRecherchee >> Rechercher la 1re occurrence en partant de la fin >> trouve, posCourante
    while ((!trouve) && (posCourante >= 0))
    {
        if (tabEntiers[posCourante] == valRecherchee)
        {
            trouve = true;
        }
        else
        {
            posCourante = posCourante - 1;
        }
    }

    // 4. trouve, posCourante >> Afficher le résultat >> (écran)
    if (trouve)
    {
        cout << "Derniere occurrence de " << valRecherchee << " trouvee a l'indice : " << posCourante << endl;
    }
    else
    {
        cout << "La valeur " << valRecherchee << " n'est pas dans le tableau." << endl;
    }

    return 0;
}
KATA 2 OFFICIEL (OSINT) • EXERCICE 8 / 9 • CEINTURE MARRON Modèle : La recherche de première occurrence (recherche de la première anomalie de signe entre deux cases consécutives)

Kata 2 Officiel — Ex. 8 : Vérifier si toutes les valeurs de {1, -1, 1, -1, 1, -1} sont de signe opposé à la précédente

🎯 Énoncé & But de l'exercice :
Vérifier et afficher si toutes les valeurs du tableau {1, -1, 1, -1, 1, -1} sont bien de signe strictement opposé à la valeur précédente.
🧠 Justification officielle du modèle :
Énoncé réel du Kata 2 (Ex. 8) : pour prouver qu'une propriété est vraie partout, on cherche la première occurrence d'un contre-exemple (deux valeurs consécutives de même signe, c.-à-d. dont le produit est >= 0, en partant de l'indice 1). Dès qu'une anomalie est détectée, on arrête immédiatement la boucle.
/**
 * Numéro du groupe : 16 (TP4)
 * Nom du groupe : Les Flèches de la Précision
 * Étudiants : Matei De Saint Leger, Nicolas Gence, Jules Tison
 * Numéro de Kata : Kata 2
 * Numéro de l'exercice : 8 (Ceinture Marron)
 * But de l'exercice : Vérifier et afficher si toutes les valeurs d'un tableau sont de signe opposé à la valeur précédente.
 * Modèle(s) d'algorithme(s) choisi(s) : La recherche de première occurrence
 * Brève justification du ou des modèles choisis : On recherche la première occurrence d'une anomalie (deux cases consécutives tabEntiers[posCourante] et tabEntiers[posCourante - 1] ayant le même signe) à partir de l'indice 1.
 * Remarques éventuelles : Deux nombres sont de signes strictement opposés si et seulement si leur produit est strictement négatif (< 0).
 */
#include <iostream>
using namespace std;

int main()
{
    // CONSTANTES
    const unsigned short int TAILLE_TAB = 6; // Nombre d'éléments du tableau à vérifier

    // VARIABLES
    int tabEntiers[TAILLE_TAB] = {1, -1, 1, -1, 1, -1}; // Tableau d'entiers dont on vérifie l'alternance de signe

Recherche de la position de la première voyelle dans un mot (Modèle 5 : Recherche de 1re occurrence)

🎯 But de l'exercice :
Rechercher et afficher l'indice de la première voyelle présente dans une chaîne de caractères (ou indiquer que le mot ne contient aucune voyelle).
🧠 Justification officielle du modèle :
Dès que la première voyelle est rencontrée dans la chaîne, il est inutile et pénalisant de poursuivre le parcours : on applique le modèle de recherche de première occurrence avec un booléen trouve et un arrêt dès détection.
/**
 * Numéro du groupe : 16 (TP4)
 * Nom du groupe : Les Flèches de la Précision
 * Étudiants : Matei De Saint Leger, Nicolas Gence, Jules Tison
 * Numéro de Kata : Kata d'entraînement (Modèle 5 - Cours 07 & TD7 Ex. 7a)
 * Numéro de l'exercice : 6 (Ceinture Verte)
 * But de l'exercice : Afficher la position de la première voyelle d'une chaîne de caractères.
 * Modèle(s) d'algorithme(s) choisi(s) : La recherche de première occurrence
 * Brève justification du ou des modèles choisis : Le parcours doit s'arrêter immédiatement dès que la première voyelle est localisée ou lorsque la fin de la chaîne est atteinte.
 * Remarques éventuelles : Conforme au diaporama 07-modeles-algos-basiques (slides 25 à 38) de M. Etcheverry.
 */
#include <iostream>
#include <string>
using namespace std;

int main()
{
    // VARIABLES
    string mot;              // Chaîne de caractères dans laquelle on recherche une voyelle
    unsigned int posCourante; // Position courante d'inspection dans la chaîne mot
    unsigned int nbCaracteres; // Longueur totale de la chaîne mot
    bool trouve;             // Indique si une première voyelle a été trouvée
    char carCourant;         // Caractère courant inspecté à la position posCourante

    // TRAITEMENTS
    // Initialiser la chaîne à analyser
    mot = "algorithmique";
    nbCaracteres = static_cast<unsigned int>(mot.size());

    // Initialiser la recherche sur le premier caractère (Modèle : Recherche de 1re occurrence)
    trouve = false;
    posCourante = 0;

    // Effectuer la recherche tant qu'on n'a pas trouvé et qu'il reste des caractères
    while ((!trouve) && (posCourante < nbCaracteres))
    {
        carCourant = mot[posCourante];
        if ((carCourant == 'a') || (carCourant == 'e') || (carCourant == 'i') ||
            (carCourant == 'o') || (carCourant == 'u') || (carCourant == 'y'))
        {
            trouve = true;
        }
        else
        {
            posCourante = posCourante + 1;
        }
    }

    // Déterminer et afficher le résultat de la recherche
    if (trouve)
    {
        cout << "Premiere voyelle '" << mot[posCourante]
             << "' trouvee a la position (indice) : " << posCourante << endl;
    }
    else
    {
        cout << "Aucune voyelle n'est presente dans le mot : " << mot << endl;
    }

    return 0;
}

 * Brève justification du ou des modèles choisis : Chaque élément de la première moitié du tableau (0 à NB_CASES/2 - 1) est systématiquement échangé avec son élément symétrique (NB_CASES - 1 - i) grâce au modèle d'échange de deux valeurs.

Détection de palindrome par recherche de première discordance (Modèle 5 adapté)

🎯 But de l'exercice :
Déterminer si une chaîne de caractères en minuscules est un palindrome (ex. 'kayak', 'radar') en s'arrêtant dès la première différence entre deux caractères symétriques.
🧠 Justification officielle du modèle :
Un mot n'est pas un palindrome dès qu'il existe une position i dans la première moitié telle que mot[i] != mot[taille - 1 - i]. On adapte donc le modèle de recherche de première occurrence pour chercher la première discordance entre caractères symétriques.
/**
 * Numéro du groupe : 16 (TP4)
 * Nom du groupe : Les Flèches de la Précision
 * Étudiants : Matei De Saint Leger, Nicolas Gence, Jules Tison
 * Numéro de Kata : Kata d'entraînement (Modèle 5 adapté - TD7 Ex. 8)
 * Numéro de l'exercice : 8 (Ceinture Marron)
 * But de l'exercice : Déterminer si une chaîne de caractères est un palindrome sans parcourir inutilement toute la chaîne en cas d'échec.
 * Modèle(s) d'algorithme(s) choisi(s) : La recherche de première occurrence
 * Brève justification du ou des modèles choisis : On recherche la première occurrence d'une différence entre mot[posGauche] et son symétrique mot[posDroite]. Dès qu'une différence est trouvée, on arrête immédiatement la boucle.
 * Remarques éventuelles : Seuil de validation Ceinture Marron en défense collective >= 16,01 / 20.
 */
#include <iostream>
#include <string>
using namespace std;

int main()
{
    // VARIABLES
    string mot;                  // Mot en minuscules à analyser
    unsigned int nbCaracteres;   // Nombre total de caractères du mot
    unsigned int posGauche;      // Indice courant partant du début du mot
    unsigned int posDroite;      // Indice symétrique partant de la fin du mot
    bool differenceTrouvee;      // Indique si deux lettres symétriques différentes ont été détectées

    // TRAITEMENTS
    // Initialiser le mot à tester
    mot = "kayak";
    nbCaracteres = static_cast<unsigned int>(mot.size());

    // Initialiser la recherche de première discordance
    differenceTrouvee = false;
    posGauche = 0;

    // Parcourir tant qu'aucune différence n'est trouvée et que la moitié n'est pas dépassée
    while ((!differenceTrouvee) && (posGauche < (nbCaracteres / 2)))
    {
        posDroite = nbCaracteres - 1 - posGauche;
        if (mot[posGauche] != mot[posDroite])
        {
            differenceTrouvee = true;
        }
        else
        {
            posGauche = posGauche + 1;
        }
    }

    // Conclure sur la nature palindromique du mot
    if (!differenceTrouvee)
    {
        cout << "Le mot '" << mot << "' EST un palindrome." << endl;
    }
    else
    {
        cout << "Le mot '" << mot << "' N'EST PAS un palindrome (difference en position "
             << posGauche << ")." << endl;
    }

    return 0;
}

Partitionnement Pair / Impair d'un tableau par échange aux extrémités (Modèles 1 + 4 + 5 combinés — Niveau Ceinture Noire)

🎯 But de l'exercice :
Regrouper toutes les valeurs paires au début d'un tableau d'entiers et toutes les valeurs impaires à la fin du tableau en un seul parcours à deux pointeurs d'indices (indPair et indImpair), puis afficher le tableau partitionné.
🧠 Justification officielle du modèle :
Inspiré directement du fichier d'évaluation etudiant001.cpp du dépôt code-explorer de M. Patrick Etcheverry : on maintient une frontière gauche (indPair) et une frontière droite (indImpair) qui convergent vers le milieu. Lorsqu'une valeur impaire est rencontrée à gauche, elle est échangée (Modèle 1 : Swap) avec la case à la frontière impaire.
/**
 * Numéro du groupe : 16 (TP4)
 * Nom du groupe : Les Flèches de la Précision
 * Étudiants : Matei De Saint Leger, Nicolas Gence, Jules Tison
 * Numéro de Kata : Kata d'entraînement (Modèles combinés - Référence code-explorer/etudiant001.cpp)
 * Numéro de l'exercice : 9 (Ceinture Noire)
 * But de l'exercice : Partitionner sur place un tableau d'entiers en plaçant les nombres pairs en tête et les nombres impairs en fin de tableau.
 * Modèle(s) d'algorithme(s) choisi(s) : Le parcours complet avec traitement conditionné (adapté à deux indices convergents) + L'échange de deux valeurs
 * Brève justification du ou des modèles choisis : Tous les éléments doivent être examinés jusqu'au croisement des indices indPair et indImpair ; si tab[indPair] est impair, on applique le modèle d'échange de deux valeurs avec tab[indImpair] et on recule indImpair.
 * Remarques éventuelles : Seuil de validation Ceinture Noire en défense collective >= 18,01 / 20 ! Code corrigé sans les défauts de nommage/typage de etudiant001.cpp.
 */
#include <iostream>
using namespace std;

int main()
{
    // CONSTANTES
    const unsigned short int NB_CASES = 10; // Nombre d'éléments du tableau à partitionner

    // VARIABLES
    int tabValeurs[NB_CASES] = {15, 12, 8, 9, 4, 17, 5, 13, 11, 14}; // Tableau d'entiers à trier (pairs à gauche, impairs à droite)
    unsigned short int indPair;   // Indice courant de progression des valeurs paires (depuis le début)
    unsigned short int indImpair; // Indice courant de placement des valeurs impaires (depuis la fin)
    int copieValeur;              // Variable temporaire permettant l'échange de deux cases
    unsigned short int i;         // Indice d'affichage final du tableau

    // TRAITEMENTS
    // 1. Initialiser les deux indices aux extrémités du tableau
    indPair = 0;
    indImpair = NB_CASES - 1;

    // 2. Partitionner le tableau tant que les deux indices ne se sont pas rejoints
    while (indPair < indImpair)
    {
        if ((tabValeurs[indPair] % 2) == 0)
        {
            // La valeur est déjà paire : on avance la frontière gauche
            indPair = indPair + 1;
        }
        else
        {
            // La valeur est impaire : on l'échange avec tabValeurs[indImpair] (Modèle : Échange de 2 valeurs)
            copieValeur = tabValeurs[indPair];
            tabValeurs[indPair] = tabValeurs[indImpair];
            tabValeurs[indImpair] = copieValeur;

            // On recule la frontière droite des nombres impairs
            indImpair = indImpair - 1;
        }
    }

    // 3. Afficher le tableau partitionné (Modèle : Parcours complet systématique)
    cout << "Tableau partitionne (Pairs puis Impairs) : ";
    for (i = 0; i <= NB_CASES - 1; i++)
    {
        cout << tabValeurs[i] << " ";
    }
    cout << endl;

    return 0;
}
