Chapitre 4 : Modèle de Von Neumann, CPU & Cycle Fetch-Decode-Execute

Composants fondamentaux (CPU, RAM, Bus, E/S), registres PC/IR/ACC/SP/PSW, décomposition temporelle de l'instruction machine et pipeline.

1. Le Modèle Fondateur de John von Neumann (1945)

Avant Von Neumann, les machines (comme l'ENIAC) étaient reconfigurées manuellement par câblage pour chaque nouveau problème. La révolution conceptuelle de l'architecture de Von Neumann est le principe du programme enregistré :

Règle & Définition Fondamentale :

Principe Fondateur : Les instructions du programme et les données numériques résident dans la même mémoire centrale sous forme de mots binaires indifférenciés. C'est l'état du processeur qui détermine si un octet est interprété comme une instruction ou comme une donnée.

2. Les Composants Fondamentaux de la Machine de Von Neumann

  • Le Processeur (CPU - Central Processing Unit) :
    • L'Unité Arithmétique et Logique (UAL / ALU) : Exécute les opérations arithmétiques (+, -, *, /) et logiques (AND, OR, NOT, décalages).
    • L'Unité de Commande (UC / Control Unit) : Chef d'orchestre qui cadence et coordonne l'exécution de toutes les instructions.
    • Le Banc de Registres : Mémoires ultra-rapides intégrées au cœur du silicium du CPU :
      • PC (Program Counter / Compteur Ordinal) : Contient l'adresse mémoire de la prochaine instruction à exécuter.
      • RI (Instruction Register / Registre d'Instruction) : Contient le code binaire de l'instruction en cours de décodage.
      • ACC (Accumulateur) : Registre de travail recevant les résultats immédiats des calculs de l'UAL.
      • SP (Stack Pointer / Pointeur de Pile) : Adresse du sommet de la pile d'exécution en mémoire vive.
      • FLAGS / CCR (Registre d'état) : Drapeaux de statut (Zéro Z, Négatif N, Retenue C, Dépassement V).
  • La Mémoire Centrale (RAM) : Espace linéaire de cellules adressables d'un octet chacune.
  • Les Organes d'Entrées/Sorties (E/S) : Clavier, écran, disque, interfaces réseau.
  • Les Bus Système : Fils conducteurs partagés reliant les composants :
    • Bus d'adresses (unidirectionnel CPU $\to$ RAM) : Détermine la taille maximale de mémoire adressable ($k$ fils d'adresses $\implies 2^k$ octets adressables).
    • Bus de données (bidirectionnel) : Véhicule les octets échangés.
    • Bus de commande / contrôle : Signaux de synchronisation (Read/Write, horloge, interruptions).

3. Le Cycle Fondamental Fetch - Decode - Execute

Pour chaque instruction, le processeur répète inlassablement ce cycle en 3 temps, cadencé par les impulsions de l'horloge système :

  1. 1. Recherche de l'Instruction (FETCH) :
    L'UC place le contenu du registre PC sur le bus d'adresses et émet un signal de lecture. La mémoire renvoie le mot binaire qui est stocké dans le RI. Le PC est automatiquement incrémenté pour pointer vers l'instruction suivante.
  2. 2. Décodage de l'Instruction (DECODE) :
    L'UC analyse les bits de l'instruction présente dans le RI. Elle sépare le Code Opération (OpCode) des opérandes (adresses ou registres concernés) et configure les circuits de commande.
  3. 3. Exécution (EXECUTE) :
    L'UAL effectue l'opération requise. Le résultat est transféré vers l'accumulateur ou la mémoire. Les drapeaux du registre d'état (FLAGS) sont mis à jour selon le signe et la parité du résultat.
