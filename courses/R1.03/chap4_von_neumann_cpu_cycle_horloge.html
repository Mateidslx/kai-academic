1. Le Modèle de Von Neumann vs Architecture Harvard

En 1945, le mathématicien et physicien John von Neumann publia son célèbre rapport First Draft of a Report on the EDVAC. Pour la première fois dans l'histoire des calculateurs, il introduisit le concept révolutionnaire de programme enregistré (Stored-Program Concept) : les instructions du programme et les données numériques sont stockées ensemble, indistinctement dans la même mémoire centrale sous forme de mots binaires.

Architecture de Von Neumann (1945) Standard PC/Serveurs

Une mémoire unique contient les instructions machine et les variables. Un bus commun relie la mémoire au processeur.

Le Goulot d'Étranglement de Von Neumann (Bottleneck) : Comme le bus est partagé, le CPU ne peut pas simultanément charger une instruction et lire/écrire une donnée. Le débit du processeur est physiquement limité par la bande passante de la mémoire centrale.
Architecture Harvard (1944) DSP / Microcontrôleurs

La mémoire des instructions et la mémoire des données sont physiquement distinctes et possèdent chacune leur propre bus d'adresses et de données. Le CPU peut lire une instruction tout en manipulant une donnée.

Harvard Modifié Moderne : Dans les processeurs x86 et ARM actuels, la RAM externe suit Von Neumann (unifiée), mais le premier niveau de mémoire cache interne (L1) est scindé en Harvard : L1 Instruction (L1i) et L1 Data (L1d) indépendants !

2. Anatomie Détaillée du CPU & Typologie des 3 Bus Système

Les 3 Bus Système : Autoroutes de l'Information

Un bus est un ensemble de pistes conductrices parallèles transportant des signaux électriques logiques. Tout ordinateur repose sur 3 bus spécialisés :

1. Bus d'Adresses Unidirectionnel

Émis exclusivement par le CPU vers la mémoire et les périphériques pour désigner la case mémoire à atteindre.

Si largeur = $k$ bits $\implies$ Espace adressable maximal = $2^k$ emplacements (ex: 32 bits = $2^{32} = 4$ Gio).
2. Bus de Données Bidirectionnel

Transporte les données en lecture (Mémoire $ o$ CPU) et en écriture (CPU $ o$ Mémoire).

Largeur = taille du mot machine (8, 16, 32 ou 64 bits). Définit le volume de bits échangé à chaque cycle bus.
3. Bus de Contrôle Lignes Spécialisées

Synchronise et pilote les transferts : signaux R/W (Read / Write), signal d'horloge CLK, ligne de Reset, demandes d'interruptions (IRQ) et acquittements (ACK).

Les Registres Internes du Processeur

PC (Program Counter)

Ou Compteur Ordinal (CO). Contient l'adresse mémoire de la prochaine instruction à exécuter. Incrémenté automatiquement dès la fin du Fetch.

RI (Instruction Register)

Contient le code binaire machine de l'instruction en cours d'exécution. C'est son contenu qui est envoyé au décodeur de l'Unité de Commande.

ACC (Accumulateur)

Registre de calcul principal de l'UAL (ALU). Stocke l'un des opérandes avant le calcul et recueille le résultat immédiat après le calcul.

R-FLAGS / CCR (État)

Contient les drapeaux d'état mis à jour après chaque calcul : Z (Zero), N (Négatif), C (Carry / retenue), V (Overflow).

MAR (Memory Address Reg)

Connecté directement au bus d'adresses. Contient l'adresse physique mémoire que le CPU souhaite lire ou écrire.

MDR (Memory Data Reg)

Connecté directement au bus de données. Sert de tampon d'échange pour les données lues depuis la RAM ou à écrire en RAM.

3. Le Cycle d'Exécution d'une Instruction en Micro-Opérations RTL

Chaque instruction élémentaire exécutée par un processeur se décompose en une séquence d'étapes cadencées par le signal d'horloge. Au formalisme RTL (Register Transfer Level), voici le déroulement absolu :

Phase Étape Horloge Micro-Opération RTL Composants & Bus Impliqués Rôle Précis
1. FETCH
(Recherche)		 T₀ MAR $\leftarrow$ PC Bus interne CPU L'adresse de l'instruction pointée par le PC est copiée dans le registre d'adresse mémoire MAR.
T₁ MDR $\leftarrow$ RAM[MAR]
PC $\leftarrow$ PC + 1		 Bus d'adresses, Bus de données, Bus de contrôle (Read) La RAM renvoie le mot d'instruction sur le bus de données dans MDR. Le PC est incrémenté immédiatement pour pointer l'instruction suivante !
T₂ RI $\leftarrow$ MDR Bus interne Le code machine est transféré dans le Registre d'Instruction.
2. DECODE
(Décodage)		 T₃ Opcode $\leftarrow$ RI[Opcode]
Opérandes $\leftarrow$ RI[Opérandes]		 Unité de Commande (Séquenceur) L'unité de contrôle sépare le Code Opération (qui dit QUELLE opération faire : ADD, LOAD, JUMP) et les adresses/registres cibles.
3. EXECUTE
(Exécution & WB)		 T₄ ACC $\leftarrow$ ACC + Opérande UAL (ALU), R-FLAGS L'UAL effectue l'opération arithmétique ou logique et met à jour les drapeaux Z, N, C, V.
T₅ Registre / RAM $\leftarrow$ Résultat Bus interne ou Bus données Write-back : écriture du résultat final dans sa destination.

L'Équation Fondamentale des Performances Processeur

Le temps total d'exécution $T_{ ext{exec}}$ nécessaire pour exécuter un programme de $N$ instructions est donné par :

T_exec = N_instructions × CPI_moyen × τ = (N_instructions × CPI_moyen) / Fréquence

• $N$ : Nombre d'instructions machine exécutées (dépend du compilateur et de l'algorithme).

• $ ext{CPI}$ : Cycles Per Instruction moyen (nombre de cycles d'horloge consommés par instruction, dépend de la micro-architecture).

• $ au = 1/f$ : Période de l'horloge en secondes (dépend de la finesse de gravure et de la fréquence en GHz).

4. Atelier Pièges d'Examen de M. Moulin

1 À quel moment exact le PC est-il incrémenté ?

Erreur très courante : Répondre « à la fin de l'instruction, après l'exécution ».
Réalité matérielle : Le Program Counter (PC) est incrémenté immédiatement dès que l'instruction a été chargée depuis la mémoire (phase Fetch), avant même que l'instruction ne soit décodée ou exécutée ! C'est ce qui permet aux instructions de saut (JUMP/BRANCH) de calculer des offsets relatifs par rapport à l'adresse de l'instruction suivante ($PC + ext{offset}$).

2 Calcul de l'espace mémoire adressable : Attention à l'unité !

Si un bus d'adresse possède 24 bits : il génère $2^{24} = 16\,777\,216$ adresses différentes. Si la mémoire est adressable par octet (8 bits), la capacité est de $16$ Mio. Mais si la mémoire est organisée en mots de 16 bits (2 octets), la capacité maximale est de $16 ext{ M mots} imes 2 ext{ octets} = 32$ Mio ! Vérifiez toujours si l'énoncé de M. Moulin précise « adressable par octet » ou « par mot ».

3 Confondre largeur du bus d'adresses et largeur du bus de données

Le bus d'adresses détermine combien de cases différentes on peut nommer. Le bus de données détermine la largeur de chaque case (combien de bits voyagent en un seul transfert). Un processeur avec un bus d'adresse de 32 bits et un bus de données de 64 bits possède un espace de $4$ milliards d'adresses et transfère 8 octets à la fois.

5. Exercices Résolus Pas-à-Pas (TD Type M. Moulin)

Exercice : Dimensionnement de Mémoire & Comparaison de Performances CPU Partiel R1.03

Énoncé : Un programmeur hésite entre deux processeurs pour faire tourner une suite de $10^9$ instructions :
• CPU A : Fréquence $f_A = 4.0 ext{ GHz}$, avec un CPI moyen de $1.6$.
• CPU B : Fréquence $f_B = 5.0 ext{ GHz}$, avec un CPI moyen de $2.2$.
Lequel est le plus rapide et quel est le gain de temps en secondes ?

Solution Détaillée :

1. Calcul du temps d'exécution sur le CPU A :
T_A = (N × CPI_A) / f_A = (10⁹ × 1.6) / (4.0 × 10⁹) = 1.6 / 4.0 = 0.400 seconde.

2. Calcul du temps d'exécution sur le CPU B :
T_B = (N × CPI_B) / f_B = (10⁹ × 2.2) / (5.0 × 10⁹) = 2.2 / 5.0 = 0.440 seconde.

Conclusion : Le CPU A est plus rapide que le CPU B (0.400 s contre 0.440 s, soit 10% de vitesse en plus) malgré une fréquence plus basse ! Cela prouve magistralement que la fréquence brute (les GHz) ne suffit pas : l'efficacité de la micro-architecture (un CPI bas) est tout aussi primordiale.

4 Questions
QUESTION 1 / 4 Registres CPU

Quel registre contient le code binaire de l'instruction qui est en train d'être décodée et exécutée ?

Explication : C'est le RI (Registre d'Instruction) qui charge et conserve le code machine binaire de l'instruction en cours. Le PC, lui, ne contient que l'adresse de la PROCHAINE instruction.
QUESTION 2 / 4 Bus & Mémoire

Un microprocesseur dispose d'un bus d'adresses de 36 bits et d'une mémoire adressable par octet. Quelle est la taille maximale de la mémoire adressable ?

Explication : Avec 36 bits d'adresse, on peut indexer $2^{36}$ cases distinctes. Puisque chaque case contient 1 octet, l'espace mémoire total est de $2^{36}$ octets $= 2^6 imes 2^{30} ext{ octets} = 64 imes 1 ext{ Gio} = 64 ext{ Gio}$. (C'était exactement l'extension PAE des processeurs 32 bits).
QUESTION 3 / 4 Architecture

Qu'est-ce que le « goulot d'étranglement de Von Neumann » (Von Neumann Bottleneck) ?

Explication : Dans une architecture de Von Neumann pure, le chemin de communication entre la CPU et la mémoire est unique. Même si le CPU est infiniment rapide, il doit attendre que les transferts séquentiels d'instructions et de données se succèdent sur ce bus partagé.
QUESTION 4 / 4 Sens des Bus

Parmi les affirmations suivantes concernant les bus d'un microprocesseur, laquelle est VRAIE ?

Explication : C'est le maître de bus (le processeur) qui génère l'adresse de destination, le bus d'adresses est donc unidirectionnel sortant du CPU. En revanche, le bus de données transporte les mots dans les deux sens : en lecture (de la RAM vers le CPU) et en écriture (du CPU vers la RAM).
