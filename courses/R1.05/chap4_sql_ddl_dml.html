Chapitre 4 : SQL DDL & DML : Création de Tables, Contraintes & Manipulation

Création rigoureuse de tables avec contraintes déclaratives : PRIMARY KEY, FOREIGN KEY avec ON DELETE CASCADE, CHECK, UNIQUE, NOT NULL. Insertion, mise à jour et suppression (INSERT, UPDATE, DELETE).

1. Création de Schéma Conforme aux Standards IUT (DDL)

Voici le script complet inspiré des TP et partiels de M. Marquesuzaà (base de données sportive / restaurant) : 

-- Suppression sécurisée préalable dans l'ordre inverse des dépendances
DROP TABLE Note CASCADE CONSTRAINTS;
DROP TABLE Controle CASCADE CONSTRAINTS;
DROP TABLE Etudiant CASCADE CONSTRAINTS;
DROP TABLE GroupeTD CASCADE CONSTRAINTS;

-- 1. Table GroupeTD (Entité indépendante)
CREATE TABLE GroupeTD (
    idGroupe NUMBER(4) CONSTRAINT pk_groupetd PRIMARY KEY,
    codeGroupe VARCHAR2(10) CONSTRAINT uq_code_groupe UNIQUE NOT NULL,
    effectifMax NUMBER(2) DEFAULT 28 CONSTRAINT ck_effectif CHECK (effectifMax BETWEEN 10 AND 35)
);

-- 2. Table Etudiant (Clé étrangère vers GroupeTD)
CREATE TABLE Etudiant (
    idEtudiant NUMBER(8) CONSTRAINT pk_etudiant PRIMARY KEY,
    nom VARCHAR2(50) NOT NULL,
    prenom VARCHAR2(50) NOT NULL,
    email VARCHAR2(100) CONSTRAINT uq_etudiant_email UNIQUE NOT NULL,
    dateNaissance DATE NOT NULL,
    idGroupe NUMBER(4) NOT NULL,
    CONSTRAINT fk_etudiant_groupe FOREIGN KEY (idGroupe) 
        REFERENCES GroupeTD(idGroupe)
);

-- 3. Table Controle
CREATE TABLE Controle (
    idControle NUMBER(6) CONSTRAINT pk_controle PRIMARY KEY,
    titreControle VARCHAR2(80) NOT NULL,
    dateControle DATE DEFAULT SYSDATE NOT NULL,
    coefficient NUMBER(3,1) DEFAULT 1.0 CONSTRAINT ck_coef CHECK (coefficient > 0)
);

-- 4. Table associative Note (Clé primaire composite & doubles clés étrangères)
CREATE TABLE Note (
    idEtudiant NUMBER(8),
    idControle NUMBER(6),
    valeurNote NUMBER(4,2) NOT NULL,
    CONSTRAINT pk_note PRIMARY KEY (idEtudiant, idControle),
    CONSTRAINT fk_note_etudiant FOREIGN KEY (idEtudiant) 
        REFERENCES Etudiant(idEtudiant) ON DELETE CASCADE,
    CONSTRAINT fk_note_controle FOREIGN KEY (idControle) 
        REFERENCES Controle(idControle) ON DELETE CASCADE,
    CONSTRAINT ck_valeur_note CHECK (valeurNote BETWEEN 0.0 AND 20.0)
);

2. Les Actions Référentielles sur les Clés Étrangères

  • ON DELETE CASCADE : Si un étudiant est supprimé, toutes ses notes associées sont automatiquement détruites pour préserver l'intégrité.
  • ON DELETE SET NULL : La clé étrangère prend la valeur NULL si l'enregistrement parent est supprimé (exige que la colonne autorise les NULL).
  • ON DELETE RESTRICT (ou comportement par défaut sans clause) : Empêche formellement la suppression d'un parent s'il possède encore des enfants référents.

3. Ordres de Manipulation de Données (DML)

-- Insertion de données valides
INSERT INTO GroupeTD (idGroupe, codeGroupe, effectifMax) VALUES (1, 'TD2', 26);
INSERT INTO Etudiant (idEtudiant, nom, prenom, email, dateNaissance, idGroupe) 
VALUES (20260001, 'DE SAINT LEGER', 'Matei', 'matei@univ-pau.fr', TO_DATE('2005-08-15', 'YYYY-MM-DD'), 1);

-- Modification sécurisée avec WHERE
UPDATE Etudiant 
SET email = 'matei.desaintleger@univ-pau.fr'
WHERE idEtudiant = 20260001;

-- Suppression ciblée
DELETE FROM Note WHERE valeurNote < 5.0;
