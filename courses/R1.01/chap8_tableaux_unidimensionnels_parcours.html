Tableaux Unidimensionnels & Parcours Algorithmiques

Conforme au formalisme de M. Patrick Etcheverry et à la pratique C de M. Sébastien Dalmau

1. Modèle Conceptuel du Tableau (Vecteur)

Un tableau unidimensionnel est une collection ordonnée d'éléments de même type, stockés de manière contiguë en mémoire. Chaque élément est accessible en temps constant O(1) grâce à son indice (indexé de 0 à N-1 en C/C++).

// Déclaration statique en C :
int notes[100]; // 100 entiers consécutifs en mémoire
const unsigned int TAILLE_MAX = 100;
unsigned int nbElements = 0; // Taille logique réelle

2. Les Algorithmes Fondamentaux d'Etcheverry

Recherche Séquentielle (Drapeau)

Arrêt précoce dès que l'élément est trouvé, évitant de parcourir inutilement la fin du tableau.

bool trouve = false;
unsigned int i = 0;
while (i < nbElements && !trouve) {
    if (tab[i] == cible) trouve = true;
    else i++;
}
Recherche du Minimum avec Indice

Toujours initialiser l'indice minimum à 0 et comparer à partir du deuxième élément (indice 1).

unsigned int indMin = 0;
for (unsigned int i = 1; i < nbElements; i++) {
    if (tab[i] < tab[indMin]) indMin = i;
}
int valeurMin = tab[indMin];
