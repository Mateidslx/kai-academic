QUESTION 1 / 4 R1.01 • Ch.13

En C, comment une fonction peut-elle modifier une variable déclarée dans la fonction appelante (passage par référence simulé) ?

Explication Pédagogique : Le C ne pratique STRICTEMENT QUE le passage par valeur (copie des arguments). Pour modifier une variable externe (ex: la fameuse fonction swap(int *a, int *b)), on passe une copie de son ADRESSE mémoire. La fonction sait alors exactement où aller écrire dans la RAM de l'appelant.
QUESTION 2 / 4 R1.01 • Ch.13

Qu'est-ce que « l'arithmétique des pointeurs » en langage C lorsque l'on écrit « ptr + 1 » où ptr est un pointeur de type int* (sur une architecture où sizeof(int) = 4 octets) ?

Explication Pédagogique : Le compilateur C adapte automatiquement les calculs d'adresses au type pointé : ajouter k à un pointeur 'Type *p' décale l'adresse de k * sizeof(Type) octets. C'est pourquoi tab[i] est strictement synonyme de *(tab + i) !
QUESTION 3 / 4 R1.01 • Ch.13

Que contiennent respectivement les opérateurs & et * en langage C appliqués à une variable ?

Explication Pédagogique : Règle de syntaxe fondamentale : si int a = 5; et int *p = &a; alors p contient l'adresse mémoire de a (ex: 0x7ffd80). L'expression *p évalue le contenu de la boîte pointée par p, c'est-à-dire 5. Modifier *p = 10 modifie directement la variable a !
QUESTION 4 / 4 R1.01 • Ch.13

En langage C, comment s'effectue l'évaluation des expressions logiques utilisant les opérateurs && (ET) et || (OU) ?

Explication Pédagogique : Propriété vitale en C pour la sécurité mémoire : cela permet d'écrire sans risque 'if (ptr != NULL && *ptr == 42)'. Si ptr est NULL, le premier test est faux, donc *ptr n'est pas évalué et le programme évite un crash immédiat (Segmentation Fault) !
