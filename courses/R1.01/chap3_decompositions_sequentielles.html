Chapitre 3 : Décompositions Séquentielles & Arbres d'Actions

Règles d'enchaînement chronologique de gauche à droite, décomposition descendante, boîtes d'actions élémentaires vs composées et traçabilité des flots.

1. Les Slides Officielles du Cours (02-sequence - 60 Diapos)

2. L'Approche Descendante & Raffinement Progressif (Slide 6-10)

L'approche descendante (top-down) consiste à décomposer un problème complexe $P$ en sous-problèmes plus simples qui, à leur tour, peuvent être redécomposés jusqu'à atteindre des actions élémentaires directement traduisibles en code.

3. Formalisme Officiel de la Décomposition Séquentielle (Slide 19-27)

Dans la notation de M. Patrick Etcheverry :

  • Le problème initial $P$ et ses sous-problèmes sont représentés par des rectangles portant le nom du traitement (But à l'infinitif).
  • La décomposition est matérialisée par une double barre verticale (||) située sous le rectangle père.
  • L'ordre séquentiel d'exécution est matérialisé par une flèche horizontale orientée de gauche à droite sous la décomposition.
  • Double sens de lecture :
    • Lecture verticale : Décomposition hiérarchique (de haut en bas, du problème général vers le détail).
    • Lecture horizontale : Ordre chronologique d'exécution des sous-problèmes (de gauche à droite).

4. Représentation des Données & Schéma de Flot de Données (SFD, Slide 33-38)

Chaque sous-problème consomme des données et produit des résultats. Cette circulation d'information est notée formellement avec le symbole de flot de données >> : 

// Données nécessaires >> Nom du Sous-Problème >> Résultats produits
// Exemple concret :
// (clavier) >> Saisir les deux nombres >> nbre1, nbre2
// nbre1, nbre2 >> Calculer la somme >> somme
// somme >> Afficher le résultat >> (écran)

5. L'Opération Fondamentale d'Affectation (Slide 39-46)

L'affectation est l'opération algorithmique par laquelle on attribue une valeur à une variable en mémoire.

  • Notation algorithmique universelle : variable <- expression (flèche orientée vers la gauche).
  • En C++ : variable = expression; (opérateur =).
  • Mécanisme : L'expression à droite est intégralement évaluée, puis son résultat typé est rangé dans l'emplacement mémoire de la variable à gauche.

6. Le Cas des Résultats Intermédiaires (Slide 50-53)

Cas d'école du cours : Calculer le périmètre d'un triangle à partir des coordonnées cartésiennes de ses 3 sommets $A(x_A, y_A)$, $B(x_B, y_B)$, $C(x_C, y_C)$.

  • Sous-problème 1 : Saisir les coordonnées des 3 sommets.
  • Sous-problème 2 : Calculer les longueurs des 3 côtés $lgAB$, $lgBC$, $lgAC$ $ ightarrow$ Ces 3 longueurs sont des résultats intermédiaires (I).
  • Sous-problème 3 : Calculer le périmètre $perimetre <- lgAB + lgBC + lgAC$ $ ightarrow$ Résultat final (R).
  • Sous-problème 4 : Afficher le périmètre à l'écran.
