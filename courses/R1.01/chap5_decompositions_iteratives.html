1. Fondements des Décompositions Itératives : Pourquoi Répéter ?

Une machine se distingue de l'être humain par sa capacité à exécuter des milliards de fois la même séquence d'instructions élémentaires sans fatigue ni erreur de calcul. La décomposition itérative permet de factoriser un traitement répétitif sans dupliquer le code source.

DÉFINITION FORMELLE D'UNE BOUCLE :

Une structure itérative est composée d'un corps de boucle (le traitement élémentaire à répéter) piloté par une condition de contrôle (condition de maintien ou condition d'arrêt) qui doit impérativement évoluer à chaque itération vers un état garantissant la finitude de l'algorithme.

2. L'Arbre Décisionnel d'Etcheverry : Comment Choisir sa Boucle ?

À l'IUT d'Anglet, on ne choisit pas une boucle par habitude ou au hasard. M. Etcheverry a formalisé un arbre de décision logique rigoureux fondé sur la recommandation de Steve McConnell (Code Complete) :

for (int i=0; i<n; ++i) Avant chaque tour 0 fois (si $n \le 0$) Parcours complet d'un tableau, calculs sommatoires bornés de $1$ à $N$.

do { ... } while (!conditionArret); Après chaque tour (a posteriori) 1 fois au moins Saisie contrôlée d'une donnée : on doit obligatoirement inviter l'utilisateur à saisir au moins une fois avant de tester la validité.

3. Les 5 Motifs Algorithmiques Standards (Design Patterns d'Amphi)

Lors des évaluations de R1.01, les exercices d'algorithmique itérative se ramènent tous à la combinaison de cinq motifs canoniques à maîtriser sur le bout des doigts :

1 Le Motif Accumulateur (Somme ou Produit)

Permet d'agréger une suite de valeurs dans une variable réceptrice. Règle d'or : Toujours initialiser avec l'élément neutre de l'opération ($0$ pour l'addition, $1$ pour la multiplication) AVANT d'entrer dans la boucle. 

double somme = 0.0; // Élément neutre addition
for (int i = 0; i < nbElements; ++i)
{
    somme = somme + tableau[i];
}
2 Le Motif Compteur (Dénombrement Conditionnel)

Dénombre les éléments satisfaisant un critère logique. Initialisé à 0, incrémenté de 1 si le prédicat est vrai. 

int nbNotesSupDix = 0;
for (int i = 0; i < nbEtudiants; ++i)
{
    if (notes[i] >= 10.0)
    {
        nbNotesSupDix = nbNotesSupDix + 1;
    }
}
3 Le Motif Sentinelle (Fin de Saisie avec 999 ou -1)

Utilisé lorsque la quantité de données n'est pas connue à l'avance. Une valeur convenue hors domaine marque la fin du flux. Règle d'or : Ne JAMAIS comptabiliser la sentinelle dans la somme ou le nombre d'éléments !

4 Le Motif Recherche d'Extremum (Min / Max)

🚨 PIÈGE MAJEUR D'EXAMEN : Ne jamais initialiser max = 0; ! Si toutes les valeurs saisies sont négatives (ex: températures -5, -12, -2), votre algorithme affichera 0 comme maximum, ce qui est faux ! Initialisez toujours max et min avec la première valeur réelle saisie.

4. La Saisie Contrôlée Sécurisée (Modèle Canonique do ... while)

Ce modèle est exigé systématiquement dès qu'un programme demande une entrée utilisateur soumise à une contrainte de domaine (ex: une note entre 0 et 20) : 

float note; // Nature : D

// Modèle officiel d'amphi : répéter tant que la saisie est invalide
do
{
    cout << "Veuillez entrer une note entre 0 et 20 : ";
    cin >> note;

    if (note < 0.0 || note > 20.0)
    {
        cout << "Erreur : valeur hors bornes. Recommencez." << endl;
    }
}
while (note < 0.0 || note > 20.0);

// Ici, note est mathématiquement garantie dans [0 ; 20] !

5. Atelier Pièges d'Examen : Les Fautes Éliminatoires en Boucles

PIÈGE N°1 La Boucle Infinie par Oubli d'Incrémentation (while) Zéro Immédiat

❌ Code Bloquant

int i = 0;
while (i < 10)
{
cout << i;
// Oubli de i++ !
}

⚠️ Mécanisme du Gel

La variable i reste éternellement à 0. La condition 0 < 10 reste éternellement vraie. Le programme s'emballe, consomme 100% d'un cœur CPU et ne s'arrête jamais.

✅ Règle de Finition

int i = 0;
while (i < 10)
{
cout << i;
i = i + 1; // Obligatoire !
}
PIÈGE N°2 Division par Zéro sur Suite Vide avec Sentinelle -3 points

❌ Code Non Protégé

moyenne = somme / nbNotes;

⚠️ Scénario Fatal

Si l'utilisateur tape directement 999 (la sentinelle) dès la première invite, nbNotes vaut 0. Le processeur lève une exception arithmétique fatale.

✅ Protection Strict

if (nbNotes > 0)
moyenne = somme / nbNotes;
else
cout << "Aucune note saisie.";

6. Exercice Guidé Type Partiel : Suite de Notes & Sentinelle 999

Sujet Officiel d'Amphi : Écrire un programme complet qui lit une suite de notes au clavier, terminée par la sentinelle 999. Il calcule et affiche la moyenne, la note minimale, la note maximale et le nombre d'étudiants ayant la moyenne ($\ge 10$). Si aucune note n'est saisie, il affiche un message adapté. 

/*
 * Programme : StatistiquesPromotionNotes
 * But : Calculer moyenne, min, max et notes >= 10 d'une suite finie par 999.
 * Auteur : Matéi de Saint Leger
 */

#include <iostream>
#include <iomanip>
using namespace std;

int main (void)
{
    // =========================================================================
    // CONSTANTES
    // =========================================================================
    const float SENTINELLE = 999.0;

    // =========================================================================
    // VARIABLES
    // =========================================================================
    float note;            // Note courante saisie (Nature : D)
    float somme = 0.0;     // Accumulateur somme (Nature : INT)
    int nbNotes = 0;       // Compteur total (Nature : INT)
    int nbAdmis = 0;       // Compteur de notes >= 10 (Nature : INT)
    float noteMin;         // Note la plus basse (Nature : R)
    float noteMax;         // Note la plus haute (Nature : R)
    float moyenne;         // Moyenne arithmétique (Nature : R)

    // =========================================================================
    // TRAITEMENTS AVEC BOUCLE TANT QUE (SENTINELLE)
    // =========================================================================
    cout << "Entrez une note (ou 999 pour terminer) : ";
    cin >> note;

    // Traitement préalable de la première valeur pour initialiser Min et Max
    if (note != SENTINELLE)
    {
        noteMin = note;
        noteMax = note;

        while (note != SENTINELLE)
        {
            // Vérification de validité de la note [0 ; 20]
            if (note >= 0.0 && note <= 20.0)
            {
                somme = somme + note;
                nbNotes = nbNotes + 1;

                if (note >= 10.0)
                {
                    nbAdmis = nbAdmis + 1;
                }

                if (note < noteMin)
                {
                    noteMin = note;
                }

                if (note > noteMax)
                {
                    noteMax = note;
                }
            }
            else
            {
                cout << "Avertissement : Note " << note << " hors bornes ignoree." << endl;
            }

            // Saisie suivante pour faire progresser la condition de boucle
            cout << "Entrez la note suivante (ou 999 pour terminer) : ";
            cin >> note;
        }
    }

    // Protection contre la division par zéro si aucune note valide n'a été entrée
    if (nbNotes > 0)
    {
        moyenne = somme / nbNotes;
        cout << fixed << setprecision(2);
        cout << "
--- RÉSULTATS DE LA PROMOTION ---" << endl;
        cout << "Nombre de notes valides : " << nbNotes << endl;
        cout << "Moyenne générale        : " << moyenne << " / 20" << endl;
        cout << "Note minimale           : " << noteMin << " / 20" << endl;
        cout << "Note maximale           : " << noteMax << " / 20" << endl;
        cout << "Étudiants avec moyenne  : " << nbAdmis << endl;
    }
    else
    {
        cout << "Aucune note valide n'a ete saisie." << endl;
    }

    return 0;
}
