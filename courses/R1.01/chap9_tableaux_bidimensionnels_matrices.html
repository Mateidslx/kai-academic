Linéarisation en mémoire et parcours imbriqués

1. Linéarisation Mémoire (Row-Major Order)

En C/C++, la mémoire étant un ruban unidimensionnel à une seule dimension d'adresses, une matrice tab[NB_LIGNES][NB_COLONNES] est stockée ligne par ligne consécutive. L'élément tab[i][j] se trouve à l'adresse mémoire offset (i * NB_COLONNES) + j. 

// Produit matriciel C = A * B (A de taille N x P, B de taille P x M)
for (unsigned int i = 0; i < N; i++) {
    for (unsigned int j = 0; j < M; j++) {
        C[i][j] = 0;
        for (unsigned int k = 0; k < P; k++) {
            C[i][j] += A[i][k] * B[k][j];
        }
    }
}
