3. Procédure vs Fonction : Quand Choisir Quoi ?

Critère Procédure (08-procedures) Fonction (09-fonctions)
Rôle Principal Réaliser une action modifiant l'état du système (I/O, mise à jour, affichage). Calculer et retourner une valeur unique typée.
Valeur de retour en C++ Type void (aucune valeur retournée directement). Type explicite (int, double, bool, string) avec instruction return.

4. Les 3 Modes de Transmission de Paramètres en C++

  1. 1. Paramètre en Entrée Pure (in) $ ightarrow$ Passage par Valeur (ou Référence Constante) :
    Le sous-programme a besoin de lire la valeur de la variable sans la modifier. Une copie locale est transmise.
    En C++ : void afficher(int valeur);
    Pour les types volumineux (structures, tableaux) : void afficherGrand(const string& texte); (C++ Core Guideline F.16).
  2. 2. Paramètre en Sortie Pure (out) $ ightarrow$ Passage par Référence (&) :
    Le sous-programme produit une valeur et doit la transmettre à l'appelant via le paramètre.
    En C++ : void saisirValeur(int& resultat);
  3. 3. Paramètre en Entrée/Sortie (inout) $ ightarrow$ Passage par Référence (&) :
    Le sous-programme reçoit une variable avec une valeur initiale, et la modifie sur place.
    En C++ : void echanger(int& a, int& b); (C++ Core Guideline F.17).

5. Recommandations Officielles C++ Core Guidelines (F.16 & F.17)

  • Règle F.16 : « For "in" parameters, pass cheaply-copied types by value and others by reference to const. »
  • Règle F.17 : « For "in-out" parameters, pass by reference. »
  • Règle F.20 : « For "out" output values, prefer return values over output parameters. » (Si un sous-programme produit un seul résultat, préférez une fonction avec return plutôt qu'un paramètre par référence).

QUESTION 1 / 4 R1.01 • Ch.6

En C, comment une fonction peut-elle modifier une variable déclarée dans la fonction appelante (passage par référence simulé) ?

Explication Pédagogique : Le C ne pratique STRICTEMENT QUE le passage par valeur (copie des arguments). Pour modifier une variable externe (ex: la fameuse fonction swap(int *a, int *b)), on passe une copie de son ADRESSE mémoire. La fonction sait alors exactement où aller écrire dans la RAM de l'appelant.
QUESTION 2 / 4 R1.01 • Ch.6

Lorsqu'on passe un tableau à une fonction en C, pourquoi doit-on obligatoirement passer également sa taille en paramètre (ex: void afficher(int tab[], int taille)) ?

Explication Pédagogique : En C, 'sizeof(tab)' à l'intérieur de la fonction ne renvoie pas la taille du tableau, mais la taille d'un pointeur (8 octets sur architecture 64 bits) ! Le paramètre 'taille' explicite est donc strictement indispensable.
QUESTION 3 / 4 R1.01 • Ch.6

Quelle est la condition préalable indispensable pour pouvoir appliquer l'algorithme de Recherche Dichotomique (Binary Search) sur un tableau ?

Explication Pédagogique : La recherche dichotomique compare l'élément cherché à la valeur médiane. Si le tableau est trié, elle sait avec certitude dans quelle moitié chercher et élimine 50% des éléments restants à chaque étape (complexité en O(log N)). Sur un tableau non trié, elle est totalement inopérante et donne un résultat faux !
QUESTION 4 / 4 R1.01 • Ch.6

Quel est le principe de fonctionnement du Tri à Bulles (Bubble Sort) ?

Explication Pédagogique : À chaque passe complète, le plus grand élément restant remonte à sa position finale à droite. Si lors d'une passe entière aucun échange n'a été effectué, on peut s'arrêter prématurément car le tableau est déjà trié (optimisation avec un booléen permut).
